# Content generation agent

This folder owns card copy, a separate “자세히 보기” article, art direction, PNG rendering, and the frontend HTML overlay contract. It follows the me;nu fan voice and editorial structure while taking only retrieved RAG evidence and chunks as factual support.

- `prompts.py`: ported me;nu voice with energetic banmal, funny character framing, absurd comparisons, callbacks, punchlines, and flexible copy length. Mild profanity and a first-person fan narrator are allowed. Slurs, targeted abuse, invented official quotes, and explicit sexual content remain out of bounds. Checkable canon and real-world claims still use retrieved evidence; that requirement does not apply to obvious jokes or exaggeration.
- `layout_director.py`: one vision decision per page helps choose crop, emphasis, and background. A readable image from the confirmed work or a related character is valid without depicting the exact scene or action. Portrait art fills nearly the whole card, square art uses most of the canvas, and ordinary landscape art is fitted by width. Ultra-wide art gets a deeper display field; a centered enlargement crop is used only for dominant layouts, while balanced layouts retain the full panorama.
- `agent.py`: one generation-queue item entry point.
- `ContentGenerationAgent.run_forever()` repeatedly reconciles stored evidence backlog rows into generation jobs, consumes jobs, saves drafts, and queues completed drafts for review. It runs only when explicitly started by a host process.
- `ani_rag.agents.content_generation.renderer` (compatibility export: `ani_rag.rendering`): creates one text-free PNG per page and returns separate copy/layout manifests; the generation worker persists each page PNG with its card record.

The PNG is never flattened with text. The frontend receives normalized page-specific `image_box` and `text_overlay_box` coordinates plus card copy. Image plates use a same-image blurred extension with the me;nu source-derived palette blend. Smooth edge masks blend the sharp art into its background without an inset rectangular frame. For dominant ultra-wide art, the sharp layer may be moderately center-cropped over the blurred full-source extension.

The generation image reader first loads locally registered work-linked assets, preferring higher-resolution assets before recency when selecting a candidate, then makes one bounded Firecrawl image search (up to eight results) using the verified RAG query and retrieved work titles. Search results are provisional: downloads are staged in a temporary directory and selected images must be readable and linked to the confirmed work. Vision helps choose crop and emphasis; it does not require a selected image to illustrate the exact card sentence, action, episode, or scene. A strong representative image from the same work or a related character is acceptable. Clearly unrelated work identity, unreadable files, visibly pixelated assets when a better candidate can be sought, and unsafe URLs remain unusable; local assets remain available as fallback, with no text-only image mode. Detail content is returned as article text, source section, and the established AI notice in that order.
