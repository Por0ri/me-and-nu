# 작품별 출처 커버리지

작품별 생성량을 같게 맞추거나 상한을 두지 않는다. 검증 가능한 고유 정보가 많은 작품은 그만큼 더 생성할 수 있다. 정보가 부족한 작품은 해당 작품의 공식 사이트와 유형별 자동수집 출처를 더 찾아 검증해 근거를 보강한다.

```powershell
uv run ani-menu work-coverage --limit 30
uv run ani-menu work-coverage --include-covered --limit 100
```

보고서는 `menu_works.csv`의 작품 ID별로 등록된 작품 전용 출처의 수와 활성/대기 상태, DB에 연결된 생성 초안 및 `ready` 콘텐츠 수를 보여준다. 기본 실행은 작품 전용 출처가 없거나 활성 출처가 없는 작품부터 표시한다. `--include-covered`는 전체 작품을 포함한다.

이 명령은 읽기용 진단이다. 작품별 생성 할당량이나 생성 상한을 설정하지 않으며, 출처 상태도 변경하지 않는다. 활성 출처는 자동으로 수집 가능한 작품별 근거가 있다는 뜻이 아니다. 따라서 낮은 커버리지 작품에는 공식 도메인·콘텐츠 유형별 출처 후보를 추가로 찾아 자동수집 검증을 통과시킨 뒤에만 활성화한다. 발견 후보/기사 URL 자체를 작품 공식 출처로 승격하지 않는다.
