# 최신 정보 수집·검증 정책

## 출처 등급

1. **공식 1차 출처**: 작품·제작위원회·배급사·행사 주최자·판매처가 직접 발표한 내용입니다.
2. **발견·교차 확인 출처**: 뉴스, 일정 서비스, 상품 매체입니다. 주제를 찾는 데 사용하고 공식 원문을 다시 찾습니다.
3. **관심도 출처**: Reddit, 루리웹 등 커뮤니티입니다. 질문과 반응만 파악하며 사실 근거로 쓰지 않습니다.

커뮤니티 중 더쿠·디시인사이드·아카라이브·에펨코리아는 출처 레지스트리에 별도로 등록되어 있지만 현재 자동 수집은 보류 상태입니다. 디시인사이드는 사전 서면 동의가 확인되기 전 자동 접근을 금지합니다. 나머지 사이트도 약관·robots·접근 조건 및 게시물·개인정보 처리 조건을 검토하기 전에는 자동 호출하지 않습니다. 앞으로 이용 조건과 기술 검증을 모두 통과한 자동 출처만 `trend_only`로 분류할 수 있으며, 이 상태의 내용은 관심도 신호로만 씁니다.

## 검증 규칙

- 정보형 콘텐츠는 공식 1차 출처가 한 곳 이상 있어야 합니다.
- 날짜, 시간, 장소, 가격, 예매·응모 조건, 지역 제한을 각각 검증합니다.
- 게시 시각과 확인 시각을 함께 기록합니다.
- 변경·연기·취소 공지가 있으면 기존 사실을 덮어쓰지 않고 상태 이력을 남깁니다.
- 확인할 수 없는 값은 추정하지 않습니다.

## 이미지 규칙

- 사용 허가 확인(`allowed`)과 공식 공개 이미지 위험 감수(`official_public_risk_accepted`)를 구분합니다. 후자는 허가를 뜻하지 않습니다.
- 사용 허가 확인(`allowed`), 공식 공개 이미지 위험 감수(`official_public_risk_accepted`), 공개 편집 출처 이미지 위험 감수(`public_editorial_risk_accepted`)를 구분합니다. 위험 감수 상태는 허가를 뜻하지 않습니다.
- 일반 작품 소개·리뷰·캐릭터·토론 등에서는 등록된 활성 출처의 공개 편집 페이지에 실제로 포함된 같은 작품 이미지도 후보로 사용할 수 있습니다. 글의 직접 삽화가 아니더라도 작품 일치가 확인되면 활용할 수 있으며, 이미지 재사용은 피하고 원문과 출처를 보존합니다.
- 이미지 위험 감수 경로는 출처 페이지 URL, 페이지와 이미지의 허용 호스트 연결, 작품 일치, 수집 시각, 출처 표기를 확인합니다. robots.txt와 접근 제한은 지키며, 무관한 도메인으로의 리디렉션은 허용하지 않습니다.
- 행사·팝업·굿즈처럼 장소·기간·상품이 핵심인 콘텐츠는 해당 행사·상품을 실제로 보여주는 근거 페이지 이미지만 연결합니다. 다른 같은 작품 이미지를 대신 끼우지 않습니다.
- `allowed`에는 권리 근거 URL·유형·확인 시각·허용 범위·출처 표기를 기록합니다. 위험 감수 이미지에는 원문 페이지 URL·확인 시각·출처 표기와 별도의 위험 상태를 기록하며 허가 범위를 추정하지 않습니다.
- 출처 확인이 안 되는 재업로드 이미지, 임의의 팬아트, 글과 무관한 도형/스톡 이미지는 계속 제외합니다.
- 이미지 위험 감수 상태는 품질 보고서에 별도 표시하고 점수에도 반영합니다. 이 점수는 법률상 허용 여부 판단이 아닙니다.
- 커뮤니티 짤, 애니 장면 캡처, 상품 구매자 사진을 그대로 복제하지 않습니다.

## 자동 수집 제한

- robots.txt, 이용약관, 호출 간격을 확인하지 않은 사이트는 자동 수집하지 않습니다.
- 로그인, 유료 구독, CAPTCHA를 우회하지 않습니다.
- 원문 전체를 저장하거나 재배포하지 않고 검증에 필요한 사실과 링크만 저장합니다.
- `config/sources.json`에서 `active`이고 `discovery_enabled`가 참인 출처만 반복 후보 탐색 대상으로 봅니다. `active`인 작품별 공식 출처라도 `discovery_enabled: false`면 후보를 찾으러 순회하지 않습니다. 발견 후보가 해당 공식 원문을 가리킬 때 원문 출처 레코드를 연결하는 것과, 그 사이트를 상시 후보 탐색 대상으로 두는 것은 별개입니다.
- 신규 커뮤니티 출처는 검토 전 `community_trend` + `manual` 또는 `terms_review`로 둡니다. 자동 어댑터는 약관·robots·접근 제한·개인정보·게시물 재사용 조건 및 실제 추출 검증을 통과해 `trend_only`로 지정된 출처에서만 허용합니다. 차단·로그인·CAPTCHA는 우회하지 않습니다.
- 자동으로 검증한 커뮤니티도 게시물 본문·댓글·작성자 식별정보·첨부 이미지/밈을 입력·저장·생성에 복제하지 않습니다. 링크와 최소한의 독자적 주제 요약만 활용하고, 커뮤니티 주장은 정보형 팩트로 승격하지 않습니다.
- `collect-page`는 활성 등록 출처만 허용합니다. 다른 도메인의 이미지 CDN은 출처별 `allowed_asset_hosts`에 등록되기 전까지 무시합니다.
- API 제공자가 저장·대량수집을 금지하면 응답을 DB나 파일에 보관하지 않고 자동 호출도 비활성화합니다.

## 비용 원칙

- 수집, 날짜 정규화, 중복 제거, URL 검사에는 LLM을 쓰지 않습니다.
- 공식 원문에서 검증된 사실만 카피 생성 모델에 전달합니다.
- 카드 전체를 한 번의 구조화 출력으로 작성합니다.
- 코드 품질 검사를 통과하지 못한 원인에 따라 필요한 노드만 다시 실행합니다.
