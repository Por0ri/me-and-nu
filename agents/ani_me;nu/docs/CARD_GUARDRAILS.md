# 카드뉴스 제작 가드레일

## 콘텐츠 방향

- 도메인은 애니메이션 하나입니다.
- 정보형을 우선하고 정보가 소진되거나 피드 호흡을 바꿀 때 유머형을 배치합니다.
- 작품의 전체 줄거리보다 지금 갈 이유, 살 이유, 볼 이유가 있는 소식을 우선합니다.
- 작품명만 바꿔 재사용할 수 있는 카드와 드립은 실패입니다.

## 이미지

- 사용 허가 확인과 사업상 위험 감수 상태를 분리합니다. 공개된 공식 이미지도 허가받은 이미지로 표시하지 않습니다.
- 소유자 결정에 따라 공식 1차 출처에서 공개한 포스터·공식 이미지는 위험 상태를 기록한 뒤 제한적으로 사용할 수 있습니다. 출처 페이지와 이미지 호스트 연결이 안 되거나 명시적 재사용 금지 조건이 있으면 제외합니다.
- 위험 감수 이미지에는 출처 URL·수집 시각·표기 문구를 기록하고 점수 보고서에 별도 표시합니다.
- 페이지마다 다른 공식 이미지를 우선합니다.
- 공식 이미지가 4장 미만일 때만 메인 이미지를 블러 배경으로 다시 사용할 수 있습니다.
- 이전 콘텐츠의 이미지는 마지막 수단 전에는 재사용하지 않습니다.
- 좌석·가격·굿즈 종류를 설명할 때 해당 내용을 보여주는 이미지인지 확인합니다.
- 사람 사진도 자동으로 자유 이용 가능하다고 보지 않습니다.

## 레이아웃

- 이미지를 칸에 억지로 자르지 않고 이미지 비율에 맞는 템플릿을 고릅니다.
- 세로형을 일괄 축소하지 않습니다. 중간 세로 비율의 일러스트·사진은 크게 배치하고, 아주 길거나 `visible_text`/`text_confidence`가 높은 안내 포스터만 포스터 전용 레이아웃으로 보냅니다.
- 모든 원본 이미지는 `contain`으로 전부 표시합니다. 크롭, 확대, 이미지 이동은 금지합니다.
- 남는 공간은 같은 이미지의 블러 배경이나 단색 배경으로 채워 여백을 디자인에 흡수합니다.
- 크롭 모드, 확대, 이동은 `IMAGE_CROP_RISK`로 즉시 차단하며 수정 루프에서 해결되지 않으면 보관합니다.
- 투명 이미지는 알파 채널의 피사체 경계를 확인하되, 원본 캔버스와 피사체를 함께 중앙 배치합니다.
- 입력 원본 자체에서 얼굴·로고·상품명·날짜가 잘렸다면 레이아웃을 바꾸어 억지로 복구하지 않고 다른 원본을 요청합니다.

## 카피와 줄바꿈

- 한 카드에 핵심 사실 하나만 둡니다.
- 고유명사·날짜·가격·수량은 `protected_phrases`로 묶습니다.
- 제목은 브라우저 자동 줄바꿈에 맡기지 않고 `title_lines`를 직접 정합니다.
- `팝 / 업`, `정 / 말`, `4 / 매`처럼 단어와 단위를 자르는 결과는 실패입니다.
- `~이고 ~이다`, `~인데 ~이다`가 연속되면 단문·명사형·질문형으로 호흡을 바꿉니다.
- 텍스트 없이 이미지만 있는 페이지는 명시적 화보 페이지가 아니면 실패입니다.

## 독립 언어 평가·검수

- 생성 에이전트와 별도인 reviewer가 카드마다 한국어 자연스러움, 번역 자연스러움, 독자 명료성,
  팬덤 흥미도, 카드 흐름을 각각 0~5점으로 평가합니다. 첫 장의 팬 훅과 마지막 장의 회수력을 특히 봅니다.
- 일본어 이미지 속 일정·응모 조건·상품명처럼 정보 전달에 필요한 문구는 카드 안에서 자연스러운 한국어로 설명합니다. “공식 사이트에서 확인하세요”처럼 핵심 정보를 독자에게 떠넘기지 않습니다.
- 번역할 외국어 문구가 없는 항목은 해당 없음으로 5점 처리할 수 있습니다. 날짜와 시각 표기는 `11:59`처럼 숫자 자체 뒤에 불필요한 마침표를 붙이지 않습니다.
- 하나라도 카드별 3점 미만이면 총점과 관계없이 생성 단계로 돌려보냅니다. 총점 85/100 및 카드별 75/100을 모두 만족해야 통과합니다.
- 안전·존중은 생성 프롬프트에서 금지 규칙을 명시하고, 독립 reviewer가 카드별 0~5점으로 평가합니다. 4점 미만이면 수정 반환합니다.
- 차별·혐오·성적 대상화·성희롱·미성년자 성적 대상화·특정 대상 괴롭힘/위협·현실 폭력 조장으로 판정되면 `SAFETY_HARMFUL_CONTENT` hard blocker를 부여합니다. 다른 점수로 상쇄할 수 없고, 수정 후 반드시 전체 재검수합니다.
- 안전 점수 10점을 별도 차원으로 두고 배점을 근거·정보 25, 이미지 적합성/권리 15, 이미지 전체 노출 10, 가독성/레이아웃 15, 한국어/번역 20, 구성/문체 5, 안전/존중 10으로 조정해 총 100점을 유지합니다.
- 혐오 표현이 원문/OCR 맥락에만 있고 카드에 재현되지 않는 경우는 차단하지 않습니다. 다만 필요한 설명도 비하 표현을 그대로 옮기지 않고 중립적으로 씁니다. 오탐 방지를 위해 단순 키워드 일치만으로 차단하지 않고, reviewer의 맥락 판단과 hard blocker를 사용합니다.
- 치명 사실·권리·이미지 잘림 오류는 점수와 무관하게 차단합니다. 페이지가 특정된 카피 오류는 해당 카드만 수정하고 나머지 카피는 보존합니다. 전역 오류만 전체 덱 수정 대상으로 삼습니다. 반려가 누적 3회면 이유와 함께 보관합니다.
- 현재 LLM 검수에는 이미지 픽셀 자체가 아니라 설명/OCR/레이아웃 메타데이터가 들어갑니다. 배포 전 실제 렌더 이미지의 별도 시각 QA가 필요한 한계입니다.

## 팬덤 훅과 엔딩

- 카피라이터는 오래 작품을 파고든 감각의 팬덤 에디터 페르소나를 사용합니다. 작품 문법을 아는 듯
  써야 하지만, 실제 개인 경험을 꾸며내거나 과한 밈으로 덕후인 척하지 않습니다.
- 첫 장은 작품 팬의 시선을 붙드는 메인 훅, 마지막 장은 앞 카드 소재를 회수하는 엔딩으로 씁니다.
  직접 호명은 여러 선택지 중 하나이며 기본 문장형으로 고정하지 않습니다.
- 말장난, 반전/대조, 질문, 작중 상황극, 건조한 한 줄, 팬 공감, 의외의 사실, 티저 중에서
  콘텐츠와 사실에 어울리는 표현 전략을 고릅니다. 선택한 방식이 주제에 맞지 않으면 억지로 웃기지 않습니다.
- 최근 생성된 최대 6개 덱의 표지·엔딩 유형을 내부적으로 비교해 같은 훅 방식을 연속 사용하지 않습니다.
  이전 원고 문구 자체는 재사용하지 않고, 표현 모드만 반복 방지 신호로 활용합니다.
- 정보 본문은 정확하게 유지하고 제목·엔딩에서 말맛을 살립니다. 확인되지 않은 긴급성·혜택은 만들지 않습니다.
- 중간 장은 정보 전달을 우선하며 모든 카드에 드립을 넣지 않습니다. 한 덱 안에서도 같은 문장 골격이나
  드립 장치가 이어지지 않게 하고, 표지와 엔딩의 리듬을 구분합니다.
- 느낌표·웃음 표시·유행어 도배는 피하되, 설명이 필요하다는 이유만으로 작품 맞춤 유머를 일괄 삭제하지 않습니다.
- 검수 에이전트는 작품 고유성, 덱 안의 반복, 최근 훅 모드와의 중복, 정보 명료성을 함께 보고 팬덤 흥미도를 평가합니다.

## 출고 조건

공식 출처, 검증 사실, 이미지 권리 상태, 이미지–내용 일치, 줄바꿈, 대비, 중복, 마지막 문구를 모두
통과하면 편집국장 에이전트가 내부 피드 대기열에 넣습니다. 검수 반려는 누적 3회째 자동 탈락 보관하며,
사람 검수 단계는 두지 않습니다. Instagram 자동 게시 기능은 별도 연동 전까지 실행하지 않습니다.
