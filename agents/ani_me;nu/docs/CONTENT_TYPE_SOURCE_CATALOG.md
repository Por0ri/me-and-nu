# 콘텐츠 유형별 출처 후보 목록

> 조사 기준일: 2026-10-21
> 목적: 콘텐츠 11개 유형의 출처 후보를 넓게 모으고, 사실 확인용·후보 발견용·트렌드 참고용을 분리한다.
> 주의: 이 목록은 **수집 후보 목록이지 자동 수집 허가 목록이 아니다.** 각 도메인·피드별 이용약관, robots.txt, 요청 빈도, 이미지 권리, 개인정보 조건을 검토하기 전에는 자동 수집을 활성화하지 않는다. 작품 소식의 최종 사실은 가능한 한 권리자·제작사·배급사·행사 주최자 등 1차 원문에서 확인한다.

## 출처 역할

- **1차 사실 출처**: 해당 사실을 발표한 권리자, 제작·배급사, 음반사, 상품 제조사, 행사 주최자·장소의 공식 원문.
- **발견 출처**: 새 후보를 찾는 뉴스 매체, 보도자료 피드, 일정 목록. 발견 내용만으로 사실을 확정하지 않는다.
- **트렌드 참고**: 커뮤니티의 화제·반응 신호. 게시글 문장·이미지·개인정보를 복제하거나 사실의 근거로 쓰지 않는다.
- **색인/데이터베이스**: 작품·인물·공식 링크 후보를 찾는 용도. 공식 원문을 대체하지 않는다.

한 사이트가 여러 유형에 쓰일 수 있다. 실제 적격성은 `콘텐츠 유형 + 작품 연관성 + 출처 역할 + 국가/지역 + 자동수집 상태`를 함께 확인한다. 이미지의 권리와 사용 가능성은 본문 출처와 별도로 기록한다.

## 특히 유의할 출처

- **AniList**: 작품별 외부 링크를 통해 공식 사이트 후보를 찾는 색인으로 유용하다. API의 `externalLinks`는 관련 외부 사이트 URL과 사이트명을 제공한다. 링크의 공식성·정확성은 별도 확인해야 하며, 우리 설정에서는 이용 조건 검토가 끝나기 전 자동 수집하지 않는다. [AniList 외부 링크 필드](https://docs.anilist.co/reference/object/mediaexternallink) · [Media 필드](https://docs.anilist.co/reference/object/media)
- **PR TIMES**: 애니 관련 발표 후보를 찾기 좋지만, 보도자료 작성 주체의 홍보성 자료다. 원문 발표 주체·세부 조건을 확인한다. [애니 태그](https://prtimes.jp/topics/keywords/anime)
- **Anime Corner**: 뉴스·인터뷰·리뷰·의견을 모두 다루므로 콘텐츠 유형별로 분류하고, 보도와 의견을 섞지 않는다. 편집 정책에서 1차 출처 우선 원칙과 뉴스/의견 구분을 밝히고 있다. [Editorial Policy](https://animecorner.me/editorial-policy/)
- **커뮤니티**: 후보 목록과 수동 참고 대상으로만 취급한다. 특히 Reddit은 RSS 종료 예정 공지가 있어 RSS 수집을 장기 전제로 삼지 않는다. [Reddit 공식 변경 안내](https://support.reddithelp.com/hc/en-us/articles/54353370049684-Changelog-October-8-2026)
- **행사 집계 사이트**: Anime Hack, AnimeMaps 등은 행사 후보 탐색에 쓸 수 있지만, DB 적재 전 공식 주최자·장소 원문에서 국가·장소·시작/종료일을 재확인한다.

## 에이전트에 반영할 때의 권장 메타데이터

출처 하나에 다음 속성을 두고, 유형 태그만으로 자동 수집을 허가하지 않는다.

```text
source_id
content_types[]          # 11개 유형 중 해당 출처가 다룰 수 있는 범위
role                     # primary / discovery / trend / index
work_ids[]               # 특정 작품 출처면 menu_work_id 연결, 일반 출처면 비움
country_scope[]          # 출처/행사 적용 국가. 독자 국가와 구분
collection_method        # API / RSS / HTML / manual
collection_status        # active / terms_review / permission_required / technical_review / blocked
terms_checked_at
robots_checked_at
min_interval_seconds
allowed_asset_hosts[]
image_rights_policy
freshness_policy
```

자동 생성 전 최소 통과 조건은 `유형 허용 + 작품 관련성 확인 + 자동 수집 상태 active + 사실의 1차 원문 확보`다. 행사·굿즈 발매는 날짜가 하루뿐이어도 시작일과 종료일을 모두 같은 날짜로 기록하고, 행사가 아닌 콘텐츠에는 행사 국가를 붙이지 않는다.

## 다음 검증 단계

1. `menu_works.csv`의 모든 작품 ID와 작품별 공식 사이트 후보를 연결한다.
2. 각 후보 URL을 11개 콘텐츠 유형에 매핑한다. 하나의 출처가 여러 유형을 지원할 수 있다.
3. 도메인 소유/운영 주체, 약관, robots.txt, 피드/API, 접근 빈도, 언어, 지역 범위를 확인한다.
4. 자동 수집은 권한·기술 확인이 끝난 소스만 활성화한다. 나머지는 후보 탐색 또는 수동 확인으로 둔다.
5. 이미지 호스트·권리 상태는 별도 검증하고, 출처의 공식성만으로 이미지 재사용을 허가하지 않는다.

## 후보 사이트별 실사용 감사 (2026-10-21)

이번 검토는 각 후보의 공개 페이지를 열어 콘텐츠 종류·운영 주체·실제 정보 형태를 확인하고, 확인 가능한 경우 `robots.txt`와 이용/편집 정책도 대조했다. **페이지 열림 = 자동수집 허가가 아니다.** 약관에 수집 허가가 명시되지 않았거나 확인하지 못한 곳은 자동 수집 보류다. 사실·날짜를 사람이 확인하고 링크를 남기는 것과 본문/이미지 복제는 별개다.

판정 기준:

- **수동 1차 사실 확인**: 운영 주체가 직접 발표한 페이지에서 사실을 확인하기 좋음. 자동화는 약관/빈도 확인 전 보류, 이미지 재사용은 별도 허가 필요.
- **발견용**: 후보를 찾는 보조 매체·목록. 원 사실은 권리자/주최자 원문에서 재확인.
- **색인/수동**: 공식 링크나 사람 프로필 등을 찾아가는 색인. 자동 수집은 보류.
- **기술 보류**: 현재 점검 도구에서 403/차단/빈 페이지 등으로 유효한 수집 경로를 확인하지 못함. 차단 우회 금지.
- **사용 제외**: robots/콘텐츠 신호가 수집을 제한하거나 공개 자료를 자동 수집하지 않는 편이 명확히 안전함.

### 감사 결과와 적용 권고

- 현재 열람 가능하고 실제 정보가 유용한 후보는 많지만, **자동 수집까지 바로 켤 수 있다고 판정한 출처는 없다.** 공개 페이지/robots 허용만으로 이용약관, 서버 요청 빈도, 상업적 재사용, AI 입력, 이미지 라이선스까지 허가된 것은 아니다.
- 먼저 쓸 만한 **수동 1차 사실 출처**는 TOHO animation, Jump Festa, Bandai Namco Cross Store, Animate Cafe, AGF Korea, 81 Produce, BANDAI SPIRITS, Animate, Lantis/FlyingDog 등이다. 이들도 기본은 사실을 확인하고 원문 링크/게시일을 저장하는 용도이며, 이미지 파일은 라이선스가 확인되기 전 캐러셀에 복사하지 않는다.
- **발견용**은 PR TIMES, Anime Hack, Anime! Anime!, MANTANWEB, Dengeki Online 등으로 제한하고, 기사 내용만으로 사실·작품 매칭을 확정하지 않는다.
- 커뮤니티 유머는 크롤링 파이프라인에 넣지 않는다. 더쿠의 콘텐츠 신호는 reference 사용 범위만 시사하며 `ai-input`이 허용됐다고 말하지 않는다. 디시인사이드·FMKorea는 일반 수집기에 대한 허가로 간주할 수 없고, 아카라이브는 정책 접근 불가다. **허가 전 원문/API/댓글/짤 수집은 금지하고, 편집자가 눈으로 확인한 주제만 원문과 분리해 독자적으로 요약**하는 형태가 안전하다.
- `config/sources.json`에서 상태가 `active`인 출처는 이 감사 결과만으로 적법성/이용허락이 확인된 것이 아니다. 특히 자동 HTML 수집·이미지 다운로드는 별도 검토가 필요하다. 이 요청은 감사·문서화 범위라 설정 상태는 임의로 바꾸지 않았다.
- 현 단계의 실사용 경로는 **RSS/공개 목록에서 제목·원문 URL 같은 최소 메타데이터 후보 → 공식 원문을 사람이 확인 → 사실·게시일·행사 기간/개최국 저장 → 이미지 권리 확인 또는 자체 제작**이다. 수집기 UA, 요청 간격, 실패 시 재시도, 보존/삭제 절차와 각 사이트의 현행 약관 검토를 끝낸 뒤에만 자동화를 별도로 승인해야 한다.

이 표는 운영/기술 검토 메모이지 법률 자문은 아니다. 접근·robots·약관은 변경될 수 있으므로 실제 배포 시 다시 확인한다.
