# 평가·검수 에이전트

콘텐츠 생성 에이전트와 분리된 최종 게이트입니다. 코드 기반 품질 검사와 독립 LLM 언어 검수를 합쳐 통과·수정 반환·수집 보완 요청·탈락 보관을 판정합니다.

- `agent.py`: 코드 검사와 별도 LLM 자연스러움·번역·명료성 평가를 결합
- `graph.py`: 평가 단계를 독립 LangGraph로 실행
- `prompt.py`: 검수 점수표와 평가 규칙

자연스러움·번역·독자 명료성·카드 흐름은 카드별 0~5점입니다. 각 항목 3점 미만이면 점수 총합과 무관하게 수정 반환합니다. 표지와 마지막 장의 팬 흥미도는 4점 이상이어야 합니다. 생성 단계에서 저장한 편집 각도와 표지/엔딩 전략을 검수 입력에 포함해 실제 카피가 기획을 살렸는지 확인합니다. 전체 품질은 85/100 이상, 카드별 점수는 75/100 이상이어야 합니다. 사실·출처·권리·이미지 잘림·표시 크기에 비해 낮은 원본 해상도 등 치명 항목은 점수로 상쇄할 수 없습니다. 페이지가 특정된 카피 오류는 해당 카드만 수정하며 나머지 카드는 보존합니다. 검수 반려가 누적 3회면 보관합니다.

대표 `content_type`은 활성 11개 유형 중 실제 캐러셀의 소재와 목적에 맞는지 별도 검수하며, 적합도 4/5 미만이면 재분류를 위해 생성 단계로 돌려보냅니다. 미분류 초안은 피드 대기열에 적재하지 않습니다.

API 키 없이 실행한 구조 시험이나 사람이 주입한 review fixture는 `offline_review_only`로 표시하며 피드에 게시 승인하지 않습니다.
