# 콘텐츠 생성 에이전트

역할: 검증된 DB 자료만 받아 3~10장 카드 카피를 작성하고, 카드별 사실 ID·이미지·HTML 오버레이 영역을 연결한 뒤 카드마다 텍스트 없는 1308×1632px 시각 PNG를 렌더링합니다. 논리 캔버스 327×408을 4배로 출력합니다.

초안은 먼저 근거 사실에 기반한 편집 각도와 표지/엔딩 표현 방식을 정한 뒤 작성합니다. 이 기획 메타데이터는 DB에 보존되어 검수자가 실제 문구와 일치하는지 확인하며, 수정 요청 시에는 지적된 카드만 교체합니다.

초안 생성 시 DB의 활성 `content_types` 목록에서 대표 유형 하나도 지정합니다. 이 추천용 타입은 `content_kind`(information/humor)와 별도이며, 현재 11개 1차 유형만 사용합니다. 서브카테고리는 아직 부여하지 않습니다.

- `graph.py`: copy writer → 이미지 비전 배치 디렉터(실패 시 결정적 레이아웃으로 대체) → card renderer를 묶는 생성 전용 LangGraph
- `../../generation.py`: LLM 카피 생성, 구조화 출력, 호출 비용 기록
- `../../layout_engine.py`: 원본 비율·해상도·카피 길이와 배치 디렉터의 제한된 제안을 조합해 레이아웃을 선택. 표지는 하단 텍스트만, 내부 페이지는 하단/좌우만 허용합니다.
- `art_director.py`: 카드 이미지와 짧은 카피 미리보기를 한 번의 저해상도 비전 요청으로 보고 텍스트 위치와 배경 처리만 선택합니다. 이미지 원본이나 카피를 수정하지 않으며 호출 토큰은 usage에 기록합니다.
- 작품 소개·리뷰·캐릭터·토론 등 일반 콘텐츠는 등록된 공개 출처에서 수집한 같은 작품 이미지를 사용할 수 있습니다. 공식 이미지가 부족하다는 이유만으로 생성을 막지 않으며, 사용 가능한 서로 다른 원본을 우선 배정합니다. 공식 캐릭터·장면을 새로 생성하거나 출처 불명의 팬아트를 끼워 넣지 않습니다.
- `renderer.py`: 카드마다 원본 이미지를 contain으로 보존하고, 같은 이미지의 배경 확장 및 HTML 영역 방향에 맞춘 그라디언트와 자연스럽게 연결한 텍스트 없는 PNG를 만듭니다. 로고·유형·카피·출처는 PNG에 넣지 않습니다.
- 행사의 장소·기간이나 굿즈 자체가 핵심인 카드에는 해당 행사/상품을 직접 보여주는 출처 이미지만 배정합니다. 일반 콘텐츠의 같은 작품 이미지 풀을 행사·굿즈 카드에 빌려 쓰지 않습니다. 원본 이미지 모드에서 파일을 읽지 못하면 빈 프레임으로 통과시키지 않고 생성을 중단합니다.
- `render_node.py`: 텍스트/카드 초안을 `generated_pending_review`로 적재하고, PNG BLOB과 카드별 렌더 키·크기를 기록합니다. `content_cards.overlay_json`은 각 페이지의 이미지 영역, 카피 영역, HTML 배치 영역, 텍스트 및 이미지 키를 제공합니다. 첫 페이지는 하단 카피만, 내부 페이지는 하단 또는 좌우 배치를 사용합니다.
- `detail_writer.py`: 검증된 사실을 바탕으로 카드 카피와 별도의 자세히 보기 글을 작성하고, 글이 사용한 fact/source ID를 `package_json`에 저장합니다. 독립 검수자는 자연스러움·사실 근거·문단 흐름을 별도로 평가합니다.
- `../../prompts.py`: 카피 작성 가이드

검수 전에도 PNG와 구조화 텍스트가 동일한 `request_id` 및 페이지 번호로 임시 DB에 저장됩니다. 검수 에이전트는 이 초안을 갱신하고, 통과한 결과만 게시 대기열로 올립니다. 피드는 PNG를 한 장의 큰 이미지로 합치지 않고 `page` 순서대로 좌우 스와이프 캐러셀로 보여줍니다. HTML 텍스트 영역은 페이지별 normalized 좌표로 저장되며, 프론트엔드 AI는 해당 좌표와 레이아웃 유형을 바탕으로 실제 텍스트 HTML을 배치할 수 있습니다. 첫 페이지는 하단 카피 영역을 우선하고, 내부 페이지는 좌우/상하 분할을 사용합니다. 원본 이미지가 잘려야만 맞는 레이아웃은 허용하지 않습니다.

이 에이전트는 자기 초안을 최종 승인하지 않습니다. PNG와 원고를 저장한 뒤 독립된 평가·검수 에이전트로 전달하며, 통과 후 게시 대기열에 저장됩니다. 해상도·중복·이미지-사실 연결 오류는 검수 실패 횟수에 포함해 시각 배정만 고친 뒤 재검수합니다. 배치 디렉터는 PNG 렌더링 전에 원본 이미지를 비전 입력으로 보지만, 독립 검수기의 판정 기준은 이 개선으로 변경되지 않습니다.

게시 피드 조회는 카드별 짧은 카피와 분리된 `package.detail_article` 객체(body, fact_ids, source_ids, markdown)를 제공해 자세히 보기 화면에서 독립된 장문을 표시할 수 있습니다. `package.detail_markdown`은 상세글 → 글과 연결된 출처 → `이 콘텐츠는 출처를 기반하여 AI로 생성한 콘텐츠입니다.` 순서로 응답 시 조립합니다. 고지 문구는 별도 컬럼/테이블에 저장하지 않습니다.
