# 콘텐츠 생성 에이전트

역할: 검증된 DB 자료만 받아 3~10장 카드 카피를 작성하고, 카드별 사실 ID·시각 모드·레이아웃을 연결한 뒤 카드마다 1308×1632px PNG를 렌더링합니다. 논리 캔버스 327×408을 4배로 출력합니다.

초안은 먼저 근거 사실에 기반한 편집 각도와 표지/엔딩 표현 방식을 정한 뒤 작성합니다. 이 기획 메타데이터는 DB에 보존되어 검수자가 실제 문구와 일치하는지 확인하며, 수정 요청 시에는 지적된 카드만 교체합니다.

초안 생성 시 DB의 활성 `content_types` 목록에서 대표 유형 하나도 지정합니다. 이 추천용 타입은 `content_kind`(information/humor)와 별도이며, 현재 11개 1차 유형만 사용합니다. 서브카테고리는 아직 부여하지 않습니다.

- `graph.py`: copy writer → deterministic layout director → card renderer를 묶는 생성 전용 LangGraph
- `../../generation.py`: LLM 카피 생성, 구조화 출력, 호출 비용 기록
- `../../layout_engine.py`: 원본 비율과 사용 가능한 텍스트 밀도를 보고 일반 세로 이미지와 긴 안내 포스터를 구분해 레이아웃을 선택
- 공식 이미지가 카드 수보다 적으면 사용 가능한 원본은 한 번씩만 쓰고 나머지는 이미지 없는 자체 편집 그래픽으로 렌더링합니다. 공식 캐릭터·장면을 새로 생성하지 않습니다.
- `renderer.py`: 카드 한 장씩 PNG로 합성. 원본은 contain으로 전부 표시하고, 여백은 원본 색상에 맞춘 연속 배경과 스크림으로 연결합니다. 한국어 어절·외래어·수량 단위가 글자 단위로 잘리지 않도록 다시 줄바꿈하며, 폰트를 줄여도 텍스트 영역을 벗어나면 렌더를 실패시킵니다. 강조색은 원본 이미지 색조를 따르고, 실제 카피 뒤에만 흐린 대비 매트를 두어 가독성을 확보합니다.
- 공식 이미지가 없는 카드는 빈 이미지 프레임 대신 주제에 맞는 편집 그래픽을 사용합니다. 원본 이미지 모드에서 파일을 읽지 못하면 빈 프레임으로 통과시키지 않고 생성을 중단합니다.
- `render_node.py`: 텍스트/카드 초안을 `generated_pending_review`로 적재하고, PNG BLOB과 카드별 렌더 키·크기를 기록
- `../../prompts.py`: 카피 작성 가이드

검수 전에도 PNG와 구조화 텍스트가 동일한 `request_id` 및 페이지 번호로 임시 DB에 저장됩니다. 검수 에이전트는 이 초안을 갱신하고, 통과한 결과만 게시 대기열로 올립니다. 피드는 PNG를 한 장의 큰 이미지로 합치지 않고 `page` 순서대로 좌우 스와이프 캐러셀로 보여줍니다. 원본 이미지가 잘려야만 맞는 레이아웃은 허용하지 않습니다.

이 에이전트는 자기 초안을 최종 승인하지 않습니다. PNG와 원고를 저장한 뒤 독립된 평가·검수 에이전트로 전달하며, 통과 후 게시 대기열에 저장됩니다. 해상도·중복·이미지-사실 연결 오류는 검수 실패 횟수에 포함해 시각 배정만 고친 뒤 재검수합니다. 현재 검수는 PNG 픽셀 자체를 비전 모델로 판독하지 않고 텍스트와 레이아웃 메타데이터를 평가합니다.
