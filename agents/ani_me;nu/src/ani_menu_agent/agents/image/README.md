# 이미지 수집 에이전트

공식 출처의 이미지 후보를 수집해 원본 파일과 별도 메타데이터를 저장합니다. 출처 URL, 권리 확인 상태, 출처 표기, 이미지 설명·OCR·관련 사실 연결을 기록하고 불명확한 이미지는 사용 후보에서 제외합니다.

- `agent.py`: 이미지 후보 수집 및 메타데이터 구성
- `download.py`: 다운로드·파일 처리
- `prompt.py`: 이미지 사용 및 설명 규칙
- 원본 바이너리는 PostgreSQL `image_blobs`의 BYTEA, 출처·권리·설명 메타데이터는 같은 PostgreSQL의 `agent_records`에 보관합니다.
