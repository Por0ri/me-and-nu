# 이미지 수집 에이전트

공식 출처의 이미지 후보를 수집해 원본 파일과 별도 메타데이터를 저장합니다. HTML 수집기는 공식 페이지의 `og:image`, 반응형 `srcset`, 지연 로딩 주소를 추출하고, 목록 페이지라면 동일한 공식 호스트 안에서 관련 상세 페이지를 최대 4개까지 확인합니다. 출처 페이지 URL, 권리 확인 상태, 출처 표기와 URL/alt-text 기반의 추정 분류를 기록합니다.

현재 구현은 이미지 픽셀을 읽어 OCR, 자막·문구 검출, 캐릭터/상품 식별을 하지 않습니다. `visible_text`, `detected_languages`, `depicted_entities` 필드는 있지만 자동 비전 분석기로 채우지 않으므로, 빈 값은 “문구 없음” 또는 “인물 미확인”을 뜻하지 않습니다. 따라서 자막이 포함된 장면의 자동 제거와 캐릭터별 이미지 일치는 아직 보장되지 않습니다. 임의로 이미지를 수정하거나 확인되지 않은 OCR을 기록하지 않습니다.

사용 가능한 공식 이미지는 카드당 한 번만 배정합니다. 카드 수보다 이미지가 적으면 같은 원본을 복제하는 대신 생성기에서 만든 편집용 타이포그래피/도형 그래픽을 씁니다. 블러는 원본 이미지 주변의 여백 처리이며, 해상도나 이미지 수의 부족을 보완하는 근거로 세지 않습니다.

- `agent.py`: 이미지 후보 수집 및 메타데이터 구성
- `download.py`: 다운로드·파일 처리
- `prompt.py`: 향후 비전 검수에 사용할 이미지 규칙 (현재 픽셀 분석 노드에는 연결되지 않음)
- 원본 바이너리는 PostgreSQL `image_blobs`의 BYTEA, 출처·권리·설명 메타데이터는 같은 PostgreSQL의 `agent_records`에 보관합니다.
