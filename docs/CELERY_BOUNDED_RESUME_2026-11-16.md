Agent가 사실 추출 후 `content_type_mismatch_skipped`로 종료할 때 사실 추출·링크 검토·OCR의 기존 usage records와 summary를 결과에 남긴다. 작품 지정 요청과 출처가 지원하지 않는 유형의 일반 요청에 같은 기록 경로를 쓴다. redirect·작품 불일치 전에 capture의 이미 발생한 비용도 먼저 수집한다.

추출을 실행했지만 usage가 비어 있으면 호출 1회와 `cost_accounting.complete=false`로 남겨 무료로 오인하지 않는다. 실제 호출 전 종료만 명시적 0회다. 과거 83388 result/manifest/검수/비용 기록은 소급 변경하지 않으며 기존 $1 예약도 유지한다. 별도 expiry·빈본문 등 모든 조기 종료 경로를 전면 수정한 것은 아니므로, 새 결과의 사용량이 누락되면 제한 Controller는 계속 중단한다.

## 제한 재개 동작

- 기존 한시 Controller를 `menu_worker.bounded_generation`으로 편입하고 과거 날짜 고정 실행 CLI는 제거했다. 진입점은 `menu_worker.bounded_resume`다. 이번 도구는 감사된 `beta-open-20261116 / one_piece_official / goods` 이력을 잇는 용도이며 범용 스케줄러가 아니다.
- 원본 완료 checkpoint 해시를 확인하고 새 파일에 records/seen/예약·감사 이력과 누적 비용을 이어받는다. 과거 시도 수는 그대로 두고 명시한 추가 시도 수만 상한에 더한다.
- 발행 전에 기존 DB 작업·attempt·결과 해시와 봉인 결과 비용을 다시 대조한다. 실제 비용으로 확인되지 않은 83388은 특정 job/attempt/result에 묶인 $1 예약을 유지하고 다른 작업에는 재사용하지 않는다.

- 새 작업 전 누적 사용량＋미계측 예약＋다음 작업 예약액을 예산과 대조한다. 사용량 누락, 생성 여부 불명확, 단건 비용 초과는 중단 사유다. $0.04 다음 작업 예약액은 확정 가격이나 단건 결제 상한이 아니며, $5도 공급자 hard cap이 아니다.

- 자동 공개나 추천 배치 실행은 포함하지 않는다. 검수 통과 번들만 내보내며 운영자 승인·서비스 적재는 별도다.

## 계획 명령

아래는 서버의 기존 state/artifact 경로를 연결한 **새 코드가 포함된 Worker Python 환경**에서 사용할 계획 명령이다. 두 승인 변수는 아직 미정이며 이 문서 작성 중 실행하지 않았다. 값이 비어 있으면 진행하지 않는다. 기존 승인 총예산 $5를 누적 목표로 유지한 예다.

```bash
: "${APPROVED_ADDITIONAL_JOBS:?추가 시도 한도를 먼저 정하세요}"
: "${APPROVED_DEADLINE:?시간대가 포함된 종료 시각을 먼저 정하세요}"
python -B -m menu_worker.bounded_resume \
  --source-checkpoint /runtime/state/checkpoint.json \
  --source-sha256 6867fc2e0287710336eb2487da1a945c8d2db36b5e598695d04a7659ee4cf991 \
  --checkpoint /runtime/state/checkpoint-resume-01.json \
  --total-budget-usd 5.00 \
  --additional-jobs "$APPROVED_ADDITIONAL_JOBS" \
  --deadline "$APPROVED_DEADLINE"
```

기본 출력의 `mode=plan`, `queue_writes=0`, 기존 비용·예약·누적 건수와 계획 해시를 검토한다. 실제 발행에는 동일한 인자와 `--apply --expected-plan-sha256`의 정확한 해시가 추가로 필요하다. 원본/새 checkpoint는 같은 state 디렉터리에 둔다. 기존 작업 DB v7, 원본 artifacts와 표지 bootstrap을 유지해야 한다. 일반 Beat/Dispatcher를 함께 켜면 이 Controller의 총량 제어를 우회하므로 병행하지 않는다. 키는 Controller가 아니라 별도 생성 Worker에만 연결한다. 현재 실행 환경에는 키가 마운트돼 있지 않고 외부 통신도 차단돼 있다.
