## 저장 규칙

- `agent_run` → `draft` → `content`를 연결해 기존 상세 API의 `full_body` 조건을 충족한다.
- 원본 49편의 제목·본문·요약을 보존한다. 원본 파일 ID, 커밋, 파일 경로, 원본 레코드, 매핑 근거와 해시를 `agent_run.input_payload`에 남긴다.
- Agent를 다시 실행하지 않는다. 가져오기 작업임을 기록하고 실행 단계·판정 로그를 만들어내지 않는다. 원본 버전이 없으면 `unknown`으로 기록한다.
- `content_type`: 영화 정보/리뷰, 음악 리뷰, 애니 사람/신작소식/리뷰/제작이야기를 구분한다.
- `subtopic`: 영화·음악은 원본 `work`의 작품·앨범명과 연도를 사용한다. 애니는 제목·본문으로 확인한 시리즈명 6개를 사용한다. 원본 `work`의 `유형: …` 문구는 작품명으로 사용하지 않는다.
- 매핑은 `backend/app/seeds/agent_content_subtopics.json`에 콘텐츠별 근거와 함께 명시한다. 이번 자료용 매핑이며 전체 서비스의 최종 분류 체계를 확정한 것은 아니다.
- `content_tag`: 콘텐츠별 작품·앨범 주제를 연결한다. 이미 등록된 영화 정보·영화 리뷰 분류도 추가 연결해 기존 필터를 유지한다.
- 출처는 콘텐츠별 URL 중복 40개를 제거해 `agent_run_source`와 `content_source`에 각각 177개를 저장한다. 첫 출처는 primary, 나머지는 citation으로 순서를 유지한다.
- 공개 상태는 `active`, 제작 유형은 `ai`. 상세 판정 로그가 원본에 포함되지 않아 `judgment_status=needs_review`로 기록한다.
- 시간대 없는 `createdAt`은 원본의 한국 시각(UTC+09:00)으로 해석한다.
- 원본 49편에는 이미지가 없어 `image_url`은 NULL이다. 기존 2편의 이미지는 유지한다.
- 사용자 계정·온보딩·구독·좋아요·북마크는 적재 대상에 포함하지 않는다.

## 재실행

`backend` 디렉터리에서 실행한다. 해당 커밋이 로컬 Git 객체에 있어야 한다.

```powershell
# 형식·매핑·출처·기존 중복 검사와 읽기 전용 미리보기
.\.venv\Scripts\python.exe -m app.seeds.agent_contents --git-ref f645df0

# 실제 적재: 전체를 한 트랜잭션으로 처리
.\.venv\Scripts\python.exe -m app.seeds.agent_contents --git-ref f645df0 --apply
```

같은 파일 ID는 `agent_run.queue_task_id`의 고유 import 키로 중복을 막는다. 동일 원본·매핑으로 재실행하면 기존 콘텐츠를 건너뛴다. 원본이나 매핑이 바뀌었거나 불완전한 이전 적재가 있으면 덮어쓰지 않고 중단한다. 사용자 수정·숨김 상태도 되돌리지 않는다. 신규 파일을 추가하려면 해당 파일의 분류 근거를 검토하고 매핑에 추가해야 한다.
