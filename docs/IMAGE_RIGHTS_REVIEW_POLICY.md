# me;nu 이미지 권리 검수 정책

> 목적: 애니메이션 공식 이미지를 무조건 금지하거나, 출처가 공식이라는 이유만으로 자동 허용하지 않는다. 이미지별 이용 근거와 게시 맥락을 기록하고, 확인된 범위 안에서 사용 여부를 판단한다.
>
> 이 문서는 운영 가드레일이며 법률 자문이나 특정 이미지의 합법성 판정이 아니다. 불명확한 사례를 자동으로 “공정이용” 또는 “허가됨”으로 분류하지 않는다.

## 기본 원칙

- 공식 이미지·보도자료·공식 SNS에 공개된 이미지도 별도의 이용 허락이나 적용 가능한 예외가 확인되지 않으면 자동 사용 허가로 간주하지 않는다.
- 무료 게시, 출처 표기, 다른 계정의 사용 사례는 그 자체로 허락의 근거가 아니다.
- 이미지 게시에는 복제·공중송신이 수반될 수 있다. 카드뉴스를 위한 자르기, 합성, 블러, 텍스트 오버레이도 원본 이미지의 변경 범위를 검토한다.
- 사용 목적은 작품·행사 정보를 전달하고 설명하는 편집 목적이다. 작품 이미지를 장식용으로 크게 내세우거나, 원본 포스터·비주얼을 대체할 정도로 사용하는 경우에는 더 엄격히 검토한다.
- me;nu 계정 운영과 앱 유입 등 서비스 홍보 맥락도 검토 기록에 포함한다. 게시물이 무료라는 이유만으로 비영리 이용으로 단정하지 않는다.
- 사실 정보와 이미지 권리는 별도 검수한다. 사실이 검증되어도 이미지 이용 권한이 자동으로 해결되는 것은 아니다.

## 이미지별 상태값

| 상태 | 의미 | 게시 처리 |
|---|---|---|
| `approved` | 계약·라이선스·공식 미디어 가이드 등 기계가 검증할 수 있는 근거가 있고, 이번 사용 범위와 모두 일치함 | 조건(출처 표기, 편집 범위, 채널, 지역, 기간)을 적용해 게시 후보 |
| `blocked_unknown` | 공식 이미지지만 이용 허락·적용 범위를 확인할 수 없거나 근거를 기계적으로 검증할 수 없음 | 자동 게시 금지. 사람 검토 대기열을 만들지 않고 자체 그래픽으로 대체 |
| `restricted` | 이용 금지 표시, 명시적 금지 조건, 권리자 차단 요청 또는 허가 범위 초과가 확인됨 | 사용 금지 및 연결된 콘텐츠 게시 차단 |
| `expired` | 허가 기간이 끝났거나 최신 가이드·계약 상태를 검증할 수 없음 | 재사용 차단, 최신 허가 근거가 다시 확인될 때까지 대체물 사용 |

사람 검토 단계는 두지 않는다. 에이전트가 이용 허락을 찾지 못하거나 조건을 명확히 비교할 수 없으면 `blocked_unknown`으로 자동 거부하고 자체 그래픽을 만든다. LLM의 자연어 추론만으로 허가를 만들어내거나 `approved`로 승격하지 않는다. `approved`는 사전에 등록된 계약·라이선스 규칙과 개별 이미지의 근거가 이번 게시의 플랫폼·목적·편집·지역·기간을 모두 허용할 때만 부여한다.

## 이미지마다 저장할 검수 정보

- `asset_id`, 원본 파일 해시, 원본 이미지 URL, 이미지가 발견된 페이지 URL, 수집 시각
- 작품/행사명, 이미지 유형(포스터·키비주얼·캐릭터·상품 사진·스크린샷 등)
- 권리자 또는 출처에 표시된 크레딧, 원문 이용 가이드/라이선스 URL 및 확인 시각
- 허용된 이용 목적·채널·지역·기간, 필요한 출처 표기, 크롭/편집 허용 여부
- 카드뉴스의 어느 페이지에서 어떤 크기·방식으로 쓸지, 사실 전달과의 관련성, 사용 면적과 원본 대체 가능성
- `rights_status`, 판정 근거, 정책/판정기 버전, 판정 시각, 재검토/삭제 기한

근거 페이지나 허용 조건을 확인할 수 없으면 해당 필드는 빈칸으로 두고 `blocked_unknown`으로 둔다. 출처 URL이나 공식 도메인만 확인했다고 허가가 성립하지 않는다.

## 검수 흐름

1. 이미지 에이전트가 공식 원문·이용 가이드·허가된 파트너 자료를 수집한다. 로봇 차단·로그인·기술 제한은 우회하지 않는다.
2. 이미지별 사용 근거와 작품 정보는 분리 저장한다. `공식 출처`와 `사용 허가 확인`은 서로 다른 필드다.
3. 권리 레지스트리/허가 목록에 권리자, 이미지 또는 적용 범위, 게시 채널, 상업성, 편집 범위, 지역, 기간, 출처 표기 조건을 구조화해 둔다. 계약이나 파트너 미디어킷이 바뀌면 버전과 효력기간도 갱신한다.
4. 권리 판정기는 원본 근거와 게시 예정 조건을 결정 규칙으로 대조한다. 하나라도 불일치·누락·만료·파싱 불확실성이 있으면 `blocked_unknown` 또는 `restricted`로 차단한다.
5. 편집국장 에이전트는 `approved` 자산만 카드에 배치할 수 있다. 이미지 권리 점수나 문장 생성 결과로 차단 상태를 뒤집을 수 없다. 통과 이미지가 부족하면 같은 이미지를 흐리거나 재사용해 권리를 우회하지 않고, 자체 그래픽으로 대체한다.
6. 허가 취소, 가이드 변경, 권리자 삭제 요청이 확인되면 연결 콘텐츠를 자동 비공개하고 이미지 해시·허가 증빙·게시 버전을 보존한다.

자동 승인 조건은 `권리 근거 존재 × 허용 사용범위 일치 × 기간 유효 × 출처조건 충족`의 논리곱이다. 어느 한 조건이라도 참이 아니거나 기계가 판단할 수 없으면 게시하지 않는다. 자동화는 불확실성을 허가로 바꾸는 기능이 아니다.

## 운영상 주의

- 출처 표시는 투명성을 위한 별도 의무일 수 있지만, 허가를 대신하지 않는다.
- 인스타그램/웹사이트의 링크·임베드도 각 플랫폼의 약관 및 권리 조건을 확인한다. 단순 링크/임베드가 모든 경우에 안전하다고 단정하지 않는다.
- 저작권 검수 결과와 사실 검수 결과를 별도로 보관한다.
- 신고·삭제 요청이 들어오면 원문·허가 증빙·게시물 버전을 보존하고, 우선 공개를 중단한 뒤 책임자가 대응한다.
