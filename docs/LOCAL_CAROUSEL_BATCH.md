# 로컬 캐러셀 반복 생성·적재

`backend/scripts/run_carousel_batch.py`는 기존 애니 에이전트를 그대로 호출해 지정한 편수만 생성하고, 구조가 완성된 결과를 로컬 테스트 DB에 적재한다. 기본 목표는 새 콘텐츠 5편이다. 목표 달성·후보 소진·시도 횟수·추정 비용 한도 중 하나에 도달하면 종료하며, 상시 실행이나 예약 작업은 등록하지 않는다.

## 실행 범위

- `Checking`에서 사용하는 `agents/ani_me;nu` 생성기 소스를 변경하지 않는다. 별도 소스 사본과 기존 가상환경을 지정하면 `PYTHONPATH`를 해당 소스로 고정한다.
- 에이전트 결과는 후보별 SQLite, `result.json`, 원본 PNG, 비밀 값이 제거된 로그로 보존한다.
- 서비스 DB는 명시한 이름과 일치하는 loopback PostgreSQL 테스트 DB만 허용한다. 이름은 `test_`로 시작하거나 `_test` 또는 `_e2e`로 끝나야 하며 연결 URL의 추가 query 옵션을 허용하지 않는다.
- 에이전트의 QC 결과·보류 사유를 그대로 기록한다. 사람이 승인한 기록을 만들거나 검수 통과로 바꾸지 않는다.
- 로컬 노출은 `active` / `needs_review`와 별도 미리보기 메타데이터를 사용한다. 피드·상세에 기존 `개발용 미리보기`, `검토 필요` 안내가 표시된다. 일반 배포 DB의 기존 공개 승인 조건은 유지된다.
- JSON 형식, 출처·팩트 참조, 만료 시각, 연속된 3~10장, 원본 PNG 해시와 1308×1632 크기를 검증한다. QC를 통과하지 못했더라도 구조가 완성된 실제 산출물은 테스트 노출할 수 있지만, PNG 누락·변조나 잘못된 구조는 적재하지 않는다.

## 후보 파일

후보는 등록된 수집 소스 ID와 HTTPS 상세 페이지 URL을 명시한다. 다음 예시의 소스와 URL은 실제 등록된 값으로 교체해야 한다.

```json
{
  "candidates": [
    {"source": "registered_source_id", "url": "https://example.com/news/one", "content_type": "news"}
  ],
  "excludedSourceUrls": ["https://example.com/already-imported"]
}
```

동일한 출처 URL은 추적용 query를 제거해 중복을 피한다. DB에 이미 있는 출처도 새 생성에서 제외한다. 후보 목록은 최대 200개, 한 배치 목표는 최대 50개다. 이 제한은 API 호출 수를 뜻하지 않는다. 한 콘텐츠 생성 안에서 추출·작성·검수 등 여러 호출이 발생한다.

실제 후보를 준비할 때는 페이지가 열리는지만 확인하지 말고 기존 에이전트의 입력 조건도 확인한다.

- `event`, `goods`, `music`, `news`는 원문 게시일이 90일을 넘으면 생성 전에 제외된다. 판매 종료일이 없어도 이 조건은 적용된다. 날짜를 바꾸어 우회하지 않는다.
- 이미지 개수와 별개로 원본 해상도·카드별 적합성·중복 여부를 확인한다. 작은 썸네일만 먼저 나오는 원문은 `--max-images 20`으로 큰 원본까지 수집할 수 있다. 원본이 없거나 부적합하면 완성된 콘텐츠로 적재하지 않는다.
- 기사 내용에 맞는 `content_type`을 지정한다. 행사 페이지에 상품 안내가 함께 있는 경우에도, 실제 이미지 분류와 요청 유형이 맞지 않으면 이미지가 제외될 수 있다. 원문의 의미를 바꾸어 유형을 지정하거나 QC 결과를 수정하지 않는다.

## 실행 예시

backend 의존성이 설치된 Python으로 저장소 루트에서 실행한다. `runtime-private.json`은 `databaseUrl`과 선택적인 `database` 항목을 가진 기존 로컬 비공개 설정 파일이다. 이 파일과 에이전트 키 파일은 커밋하지 않는다.

```powershell
python -B backend/scripts/run_carousel_batch.py `
  --agent-root C:/path/to/unchanged-agent-copy `
  --agent-python C:/path/to/agent/.venv/Scripts/python.exe `
  --credentials-file C:/path/to/agent/.env `
  --candidates C:/path/to/generation-candidates.json `
  --output-dir C:/path/to/batch-output `
  --database-config C:/path/to/runtime-private.json `
  --expected-database checking_live_e2e `
  --target 5 --max-attempts 10 --max-estimated-cost-usd 1
```

기본 실행은 DB를 읽기 전용으로 확인하고 계획만 출력한다. **동일 명령 끝에 `--apply`를 추가하면 유료 생성 호출과 로컬 DB 적재가 실행된다.** 키는 명시한 에이전트 파일만 읽으며 backend 키를 자동 검색하거나 대체하지 않는다. `--database-config`를 생략하면 현재 프로세스에 명시된 `DATABASE_URL`만 읽는다. DB 설정의 `.env` 자동 대체는 하지 않는다.

기존 소스 폴더에 `.env`가 있다면 추적 파일만 복사한 별도 소스 사본을 사용한다. 출력 폴더는 에이전트 소스 바깥의 일반 폴더여야 한다.

## 중단·재개와 비용

- 후보마다 `generating` 상태를 먼저 저장한다. `checkpoint.json`은 원자적으로 교체하고 OS 파일 잠금으로 동일 배치의 중복 실행을 막는다.
- 완성된 결과를 가진 중단 항목은 재생성하지 않고 검증·적재부터 재개한다. DB 커밋 직후 중단돼도 같은 digest를 재사용해 중복 적재를 피한다.
- 결과가 없는 중단 항목은 보존하고 건너뛴다. 같은 후보를 자동으로 다시 유료 호출하지 않는다.
- 목표를 달성한 배치를 같은 명령으로 다시 실행해도 콘텐츠가 추가되거나 LLM이 재호출되지 않는다. 후보 목록·목표·실행 제한·소스가 바뀌면 같은 출력 폴더의 재개를 거부한다.
- `--max-attempts`는 시작한 후보 수의 상한이다. 후보 하나의 실행 제한은 기본 1,200초이며 `--timeout-seconds`로 조절한다.
- 비용은 에이전트 `usage_summary` 또는 `usage_records`에 기록된 추정치를 누적한다. 누락된 시도의 비용은 기존 에이전트 정책에 맞춘 미화 0.04달러 예비액으로 계산한다.
- 추정 비용 한도는 **다음 콘텐츠 시작을 막는 기준**이다. 진행 중인 API 호출의 실제 청구 금액을 정확히 제한하는 결제 상한이 아니다. `summary.json`은 알려진 추정치와 누락분 예비액을 구분하며 실제 청구 총액을 확정했다고 표시하지 않는다.

결과는 `summary.json`, 후보별 `generation/result.json`, `staged/bundle.json`, `checkpoint.json`에서 확인한다. 종료 코드 0은 계획 확인 또는 목표 달성, 2는 한도·후보 소진으로 목표에 못 미친 종료, 1은 입력·연결 등 실행 오류다. 오류가 나면 새 배치를 무작정 시작하지 말고 기존 결과와 체크포인트를 먼저 확인한다.

## 검증

`backend/tests/test_carousel_batch_runner.py`는 실제 API 키·LLM·DB를 사용하지 않고 다음을 검증한다.

- 목표 편수·추정 비용·시도 상한
- 재실행과 DB 응답 유실 후 복구 시 중복 유료 호출·중복 적재 방지
- 중단된 생성 결과 보존, 현재 DB에 존재하는 URL 제외
- 로컬 테스트 DB 제한과 병렬 실행 잠금
- 에이전트 소스 경로 고정과 소스 변경 시 재개 차단
- 원본 검수 실패 기록 보존, 승인 기록 미생성, PNG 해시 불일치 거부

실제 5편 생성 및 화면 확인 결과는 해당 실행의 로컬 `summary.json`과 별도 점검 기록을 기준으로 한다. 이 문서만으로 실제 생성·적재 완료를 뜻하지 않는다.

`Checking` 코드로 `checking_live_e2e`에 새 콘텐츠 **5편, 25장**을 적재했다. 기존 콘텐츠 1편·3장을 유지하여 총 **6편, 28장**이다. 새 ID는 2~6이며 나츠메 상품·원피스 흰수염·던전밥 굿즈·프리렌 굿즈·나츠메 구매 특전 안내다. 모두 실제 에이전트 산출물이며, 원본 QC 결과를 보존한 검토 전 미리보기다.
