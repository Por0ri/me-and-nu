## 분류 기준

- 전체 49개: 영화 30개, 음악 13개, 애니메이션 6개. 기존 영화 분류 2개에 작품·앨범 기준 47개를 추가했습니다.
- 영화: 작품명과 연도. 기존 영화 정보·영화 리뷰 분류도 유지합니다.
- 음악: 아티스트 + 앨범명 + 연도.
- 애니메이션: 작품·시리즈명. 블리치 관련 글 3편은 같은 세부 토픽으로 묶습니다.
- 파일의 글 유형은 content.content_type에 별도로 보존합니다. 기존 영화 2개 분류와 신규 작품 분류가 함께 있는 구조입니다.
- 한 콘텐츠에 여러 세부 토픽을 연결할 수 있으므로 아래 콘텐츠 수를 모두 합하면 전체 콘텐츠 51편보다 커집니다.
- 이번 콘텐츠에 근거한 초기 목록이며 전체 서비스의 최종 관심사 분류 체계는 아닙니다. SF·힙합·작화 등 장르·관점 태그는 이번 적재에서 추가하지 않았습니다.

## 연결 예시

- 영화 새 글: 영화 → 작품명(연도), 기존 영화 정보 또는 영화 리뷰에도 연결.
- 음악 새 글: 음악 → 아티스트·앨범명(연도).
- 애니 새 글: 애니메이션 → 작품·시리즈명.

등록 정의는 subtopic, 콘텐츠와의 연결은 content_tag, 사용자의 구독은 tap_topic에 저장합니다. 이 목록 조회 과정에서 DB는 변경하지 않았습니다.
