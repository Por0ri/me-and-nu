# 추천 모델 실험 기록

me;nu 피드 추천 모델 설계 과정 기록. 실험마다 바꾼 것, 이유, 점수 변화를 남김. 점수가 떨어진 시도도 이유와 함께 기록함.

## 0. 진행 방식

| 순서 | 단계 | 내용 | 상태 |
|---|---|---|---|
| 1 | 기준 모델 (v0) | 규칙 기반 추천. 학습 없음 | 완료 |
| 2 | 채점기 (M3) | MAL 실제 시청 기록으로 추천 성능을 숫자로 측정 | 완료 |
| 3 | 작품 취향 모델 (v0.5) | 다음 편, 인기도, 같이 본 작품, AniList 태그, EASE. 채점기로 전후 비교 | 완료 (EXP-18) |
| 4 | 글 추천 + 서비스 연결 (v1) | 작품 취향 + 유형 취향 + 시의성 + 반응으로 글 점수. 매일 배치 → DB 저장 → 피드 API | 다음 |
| 5 | 유저 테스트 | 1주, 20명 이상. 실제 로그로 재평가 | 예정 |

- 학습 모델부터 시작하지 않은 이유: 기준 점수와 채점기가 없으면 학습 모델이 나아졌는지 판단 불가
- 학습 모델은 같은 시험에서 기존 방법을 확실히 이길 때만 도입. EASE(EXP-15)가 처음 통과. 딥러닝(SASRec 등)은 GPU 확보 후 같은 기준으로 검토

## 1. 채점 방식

현재 시험지 (EXP-13부터)

| 항목 | 내용 |
|---|---|
| 데이터 | MAL 공개 데이터 (`anime-db` 컨테이너의 `mal` 스키마). 시청 기록 2.2억 줄, 작품 13,379편, 2004 ~ 2022-03 |
| 표본 | 유저 5만 명 (다 본 작품 20~1000개, 2021년 이후 접속. md5 순서로 고정 추출). 기록 있는 유저 48,063명 · 851만 줄 |
| 정답 | 유저가 마지막에 다 본(completed) 작품 1개. 정답 시각 2020-01 ~ 2022-01 |
| 문제 | 정답보다 이전 기록만 주고 추천 10개 생성 |
| 채점 유저 | 21,357명 = 연습 5,000명 (설정값 고르기) + 실전 16,357명 (최종 채점) |
| 통계 | 인기도·같이 본 작품은 표본 전체 47,181명 기록으로 셈 (821만 줄). 시험 유저는 정답 전 기록만, 나머지는 2022-02 전 기록만 |
| 메인 지표 | **시리즈 Hit@10**: 정답과 같은 시리즈 작품이 추천 10개 안에 있으면 맞힘 |
| 보조 지표 | 보던 시리즈 / 새 시리즈 Hit@10 (정답 종류별), 시리즈 NDCG@10 (순위 반영), 작품 Hit@10 (정확히 그 작품) |
| 추천 규칙 | 이미 본 작품 제외, 정답 시점에 방영 전인 작품 제외, 성인 작품 제외, 같은 시리즈는 1개만 |
| 값 고르기 | 고르는 기준을 결과 보기 전에 정하고 연습 유저로만 고름. 실전은 확인용. 같은 유저로 고르고 채점하면 점수가 부풀려짐 |
| 바꾸는 기준 | 메인 지표와 보조 지표가 같이 좋아지고 연습·실전이 같은 방향일 때만 바꿈. 좋은 점과 나쁜 점이 섞이거나 차이가 거의 없으면 지금 값 유지. 시뮬레이터 결과는 가정 바꿔 보기까지 통과해야 함 (실제 유저가 아니라서) |

채점 제외 조건

| 조건 | 이유 |
|---|---|
| 마지막에 다 본 시각이 여러 작품에 겹침 | 무엇이 마지막인지 모름 |
| 정답 시각이 2020년 이전 | 오래된 기록은 날짜가 뭉쳐 있어 부정확 (예: 2004-05-11 일괄) |
| 정답 시각이 2022-02 이후 | 데이터 수집(2022-03) 직전이라 정답이 한 작품으로 몰림 (EXP-12) |
| 정답 이전 기록 5개 미만 | 취향 판단 불가 |

- 작품 취향만 측정. 콘텐츠 유형(소식·가이드 등) 취향은 MAL에 없음 → 가짜 유저 시뮬레이터로 검증 (M3-2)
- MAL 유저(해외, 2022년까지) ≠ me;nu 유저(국내 애니 팬). 절대 점수보다 방법 간 비교에 의미
- MAL 기록은 2022-03까지 → 그 뒤 작품은 채점 불가
- 실전 채점 1회 약 2분 (방법 1개, 16,357명)

## 2. 실험 기록

### 🔷 EXP-01 · v0 규칙 기반 추천

목표: 처음부터 끝까지 한 번 돌아가는 콘텐츠 추천 확보

점수 규칙

| 이유 | 점수 |
|---|---|
| 좋아하는 작품 글 | +1.5 |
| 좋아하는 유형 | +1.0 |
| 좋아하는 장르 겹침 | 겹치는 비율만큼, 최대 +1.0 |
| 새 글 | 소식은 7일, 그 외는 30일 기준으로 감소 |
| 반응 | 좋아요 +0.5, 저장 +0.8, 더볼래요 +1.0, 그만볼래요 −1.5 (같은 작품). 같은 유형에 30% 전파 |

- 후보 제외: 게시중 아님, 기간 끝난 행사, 이미 본 글
- 같은 작품 글 연속 금지, 안 본 작품의 스포일러 2등급 이상은 흐림

검증: 샘플 데이터 (작품 18, 콘텐츠 105, 페르소나 6명)

| 확인 항목 | 결과 |
|---|---|
| 취향 맞는 상위 10개 | 6명 모두 정상 |
| 이미 본 글 제외 | 정상 (저장한 체인소 맨 글 제외됨) |
| 그만볼래요 | 히로아카 글 2위·4위 → 20위·22위 |

발견된 문제

- 좋아하는 작품 글만 나옴. 6명 중 4명은 10개 전부 좋아하는 작품 글 → 새 작품 발견 불가
- 작품 가중치(+1.5)가 커서 유형 취향이 묻힘

### 🔷 EXP-02 · 채점기 구축, 기준 점수 측정

목표: 모델 개선 여부를 숫자로 판단할 시험지 확보

- 비교 기준 2개
  - 인기순: 누구에게나 같은 인기작. 이보다 못하면 의미 없음
  - 장르 취향 (v0 방식): 본 작품들의 장르 비율과 코사인 유사도. 같은 점수면 인기순. 후보는 인기 상위 2000편
- 첫 측정 (3,000명, 작품 단위, 시리즈 정리 없음)

| 방법 | 작품 Hit@10 |
|---|---|
| 인기순 | 3.1% |
| 장르 취향 (v0) | 6.6% |

- 장르 취향이 인기순의 약 2배. 개인 취향 반영 효과 확인 (→ EXP-09에서 시험지 치우침 때문으로 밝혀짐)
- 문제 발견: 추천 10개 중 노라가미 3개(본편·2기·OVA), 인기순은 진격의 거인 1·2·3기가 3자리 차지

### 🔷 EXP-03 · 같은 시리즈 1개만 추천

목표: 같은 시리즈가 추천 자리를 여러 개 차지하는 문제 해결

시리즈 묶는 방법 시도

| 시도 | 방법 | 결과 | 판단 |
|---|---|---|---|
| 1 | MAL 관계 데이터 7종(속편·외전·원작·스핀오프 등) 전부 연결 | 나루토+원피스+드래곤볼 288편, 은혼+빨간 머리 앤 317편이 한 묶음 | 실패. 콜라보 특별편이 여러 시리즈를 이어 붙임 |
| 2 | 속편·전편으로 묶고, 외전 등은 한 시리즈에만 이어질 때만 붙임 | 원피스 1편(극장판 0), 노라가미 2편(OVA 빠짐) | 실패. 관계 데이터 자체가 지저분함 (원피스 극장판 14가 드래곤볼 작품의 원작으로 표기) |
| 3 | 속편·전편 관계 + 제목 앞부분 일치 | 노라가미 4편, 원피스 44편, 진격의 거인 17편. 나루토·원피스·드래곤볼 분리 | **채택** |

- 제목 앞부분: `:` 앞만 쓰고 Season·Movie·Film·OVA·숫자 등 꼬리 제거. 예) `One Piece Movie 14: Stampede` → `one piece`
- 2편 이상 묶음 1,892개 (6,540편)

결과 (13,402명)

| 방법 | 시리즈 정리 | 시리즈 Hit@10 | 시리즈 NDCG@10 | 작품 Hit@10 |
|---|---|---|---|---|
| 인기순 | 안 함 | 5.37% | 0.028 | 3.40% |
| 인기순 | 1개씩 | 6.23% | 0.032 | 3.94% |
| 장르 취향 (v0) | 안 함 | 10.22% | 0.061 | **7.11%** |
| 장르 취향 (v0) | 1개씩 | **13.38%** | **0.075** | 5.42% |

- 시리즈 단위: 장르 취향 10.22% → 13.38% (+3.2%p, 상대 +31%). 빈자리에 다른 취향 작품이 들어옴
- 작품 단위: 장르 취향 7.11% → 5.42% (−1.7%p). 정답 대신 같은 시리즈 다른 작품이 남음
  - 예) 정답 `One Piece Film: Z` → 남은 것 `One Piece`
- 원인: 정답의 42.0%가 이미 본 시리즈의 다른 작품

결정

- **메인 지표를 시리즈 Hit@10으로 변경**
  - me;nu는 작품 관련 글을 보여주는 서비스. 원피스 극장판 글이든 원피스 글이든 같은 관심사
  - 점수 올리려고 바꾼 게 아니라 서비스 목적에 맞춘 기준. 작품 단위 점수는 보조로 계속 기록
- **같은 시리즈 1개만 추천을 기본 규칙으로 채택**

### 🔷 EXP-04 · 보던 시리즈의 다음 편 우선

목표: 정답 42%(보던 시리즈의 다른 작품)를 직접 노림

방법: 장르 취향 점수 + 다음 편 보너스

| 규칙 | 내용 |
|---|---|
| 대상 | 본 시리즈(completed·watching) 중 아직 안 본 작품 |
| 보너스 | `보너스 크기 × e^(−지난 일수 / 기간)`. 최근에 본 시리즈일수록 큼 |
| 하차 | 그 시리즈의 마지막 기록이 dropped면 보너스 없음 |
| 후보 | 인기 상위 2000편 + 보던 시리즈 작품 (인기 밖이어도 포함) |

설정값 찾기 (연습 3,000명, 시리즈 Hit@10. 같은 조건 장르 취향 12.90%)

| 보너스 \ 기간 | 30일 | 90일 | 365일 | 1095일 | 무한 |
|---|---|---|---|---|---|
| 0.3 | 14.80% | 14.97% | 18.60% | | |
| 0.5 | 15.63% | 15.60% | 21.40% | | |
| 1.0 | 15.63% | 16.17% | 24.53% | | |
| 2.0 | 15.77% | 17.23% | 25.87% | 26.00% | 19.77% |
| 5.0 | | | **26.13%** | 25.23% | 19.77% |
| 100 | | | 25.27% | 24.90% | 19.77% |

- 보너스 2~5, 기간 1~3년 구간에서 26% 안팎으로 평평함 → 최적값 근처 확인
- 기간 무한(오래전에 본 시리즈도 같은 보너스)은 19.77%로 하락 → 최근 본 시리즈 우선이 맞음
- 30·90일은 너무 짧음. MAL 기록 기준으로 다음 시즌까지 공백이 긴 경우가 많은 것으로 보임

결과 (실전 10,402명)

| 방법 | 시리즈 Hit@10 | 시리즈 NDCG@10 | 작품 Hit@10 |
|---|---|---|---|
| 인기순 | 6.23% | 0.031 | 3.96% |
| 장르 취향 (v0) | 13.52% | 0.076 | 5.39% |
| 다음 편 (2.0 / 365일) | 26.81% | 0.139 | 15.66% |
| 다음 편 (5.0 / 365일) | **26.89%** | **0.139** | **16.13%** |

- 전체 시리즈 Hit 13.52% → 26.89% (약 2배)

정답 종류별로 나눠 보기 (실전)

| 방법 | 보던 시리즈 정답 (4,374명) | 새 시리즈 정답 (6,028명) |
|---|---|---|
| 장르 취향 (v0) | 14.97% | **12.46%** |
| 다음 편 (2.0 / 365일) | 56.95% | 4.94% |
| 다음 편 (5.0 / 365일) | **59.56%** | 3.19% |

- 전체 상승은 전부 보던 시리즈 쪽에서 나옴 (15% → 60%)
- **새 시리즈 맞히기는 12.46% → 3.19% (−74%)**. 추천 10자리를 보던 시리즈가 거의 다 차지
- EXP-01에서 발견한 "좋아하는 작품 글만 나옴" 문제를 더 키우는 방향

결정

- **이대로는 채택 안 함.** 전체 점수만 보면 2배지만 새 작품 발견이 무너짐
- 다음 편 보너스 자체는 효과 확실 → 자리 수를 제한해서 다시 실험 (EXP-05)
- 앞으로 모든 실험은 **전체 + 보던 시리즈 + 새 시리즈** 세 가지 점수를 같이 기록

### 🔷 EXP-05 · 다음 편 자리 제한

목표: 다음 편 효과는 살리고 새 작품 발견은 지키기

방법

- 추천 10개 = 보던 시리즈 다음 편 **최대 N개** (앞쪽) + 나머지는 장르 취향
- 다음 편 순서는 EXP-04 점수(장르 + 보너스 5.0 / 365일) 그대로
- N 고르는 기준 (결과 보기 전에 정함): **새 시리즈 Hit@10이 장르 취향보다 10% 넘게 안 떨어지는 선에서 전체 최대**

연습 3,000명 (장르 취향 새 시리즈 12.12% → 하한 10.91%)

| N | 전체 | 보던 시리즈 | 새 시리즈 | 기준 |
|---|---|---|---|---|
| 0 (= 장르 취향) | 12.90% | 13.98% | 12.12% | 통과 |
| 1 | 16.03% | 21.84% | 11.83% | 통과 |
| **2** | **17.83%** | 27.24% | 11.03% | **통과 · 선택** |

### 🔷 EXP-08 · 짧은 기록 시험

### 🔷 EXP-10 · 인기도 섞기

목표: 새 작품 8자리에 인기도를 섞어 신규 유저·새 작품 맞히기 개선

방법

- 새 작품 8자리 점수 = 장르 유사도(0~1) + β × 인기도(0~1). 앞 2자리는 다음 편 그대로
- 인기도 = log(본 사람 수 + 1)을 1등이 1이 되게 맞춤
- 인기도 2종: 전체 기간 / **최근 30일** (정답 직전 30일 동안 기록된 수. 요즘 뜨는 작품 흉내. 최근 인기 상위 300편은 후보에 추가)
- β: 0, 0.25, 0.5, 1, 2, 4, 인기도만
- 고르는 기준 (미리 정함): 상황별로 연습 5,000명 전체 점수 최고

연습 5,000명, 기록 전체 (전체 / 새 시리즈)

| β | 전체 기간 인기 | 최근 30일 인기 |
|---|---|---|
| 0 (섞기 없음) | 14.54% / 1.32% | 14.54% / 1.32% |
| 0.25 | 16.20% / 3.20% | 19.66% / 7.08% |
| 0.5 | 17.86% / 4.89% | 22.44% / **8.36%** |
| 1 | 19.62% / 6.17% | 23.40% / 4.55% |
| 2 | 20.50% / 6.89% | **24.80%** / 3.05% |
| 4 | 20.54% / 6.85% | 24.22% / 2.11% |
| 인기도만 | 18.62% / 6.55% | 24.02% / 1.66% |

연습 5,000명, 신규 유저 (작품 1개 + 장르 3개) 전체

| β | 0 | 0.25 | 0.5 | 1 | 2 | 4 | 인기도만 |
|---|---|---|---|---|---|---|---|
| 전체 기간 인기 | 5.28% | 5.58% | 6.74% | 8.38% | 9.90% | 14.58% | **25.76%** |
| 최근 30일 인기 | 5.28% | 7.20% | 9.16% | 11.88% | 16.20% | 18.14% | 17.76% |

- 선택: 기록 전체 → **최근 30일, β=2** / 신규 유저 → **전체 기간 인기도만**

결과 (실전 33,887명, 전체 / 새 시리즈)

| 방법 | 기록 전체 | 작품 1개 | 작품 1개 + 장르 3개 |
|---|---|---|---|
| 다음 편 2자리 (섞기 없음) | 13.56% / 1.54% | 5.33% / 2.58% | 4.89% / 2.13% |
| + 최근 30일 인기 섞기 (β=2) | **23.57%** / 3.38% | 15.30% / 12.85% | 16.07% / 13.63% |
| + 전체 기간 인기도만 | 17.95% / **6.72%** | **24.99%** / **22.82%** | **24.99%** / **22.82%** |

- 기록 있는 유저: 최근 인기 섞기로 13.56% → 23.57% (+74%)
  - 늘어난 건 대부분 보던 시리즈 (28.05% → 47.92%). 요즘 뜨는 작품이 보던 시리즈의 새 시즌인 경우 (귀멸의 칼날 유곽편 등)
  - 새 시리즈 맞히기는 전체 기간 인기가 더 좋음 (6.72% vs 3.38%)
- 신규 유저: 전체 기간 인기순이 최고 (24.99%). 기록 1개로는 취향보다 "많은 사람이 좋아하는 작품"이 더 잘 맞음
- 주의: 최근 인기가 강한 데엔 귀멸의 칼날 쏠림 영향 가능 → 2022년 2월 정답 빼고 확인 (→ EXP-12)

### 🔷 EXP-11 · 같이 본 작품 (연관 규칙)

목표: 다른 유저 행동("이거 본 사람이 저것도 봄")으로 새 작품 맞히기

방법

- 인기 상위 3,000편끼리 "같이 본 유저 수" 표 작성 (정답을 뺀 기록 38,887명)
- 점수 3종 (Apriori 연관 규칙 지표. 계산은 부록 B)
  - 신뢰도(confidence): A를 본 사람 중 B도 본 비율
  - 향상도(lift): 신뢰도 ÷ B를 본 사람의 원래 비율 (같이 본 사람 5명 미만은 0)
  - 코사인: 둘의 중간
- 유저 점수 = 본 작품마다의 점수 합. 추천 = 다음 편 2자리 + 같이 본 작품 8자리
- 고르는 기준 (미리 정함): 연습 5,000명 전체 점수 최고

연습 5,000명 (전체 / 새 시리즈)

| 점수 | 기록 전체 | 작품 1개 |
|---|---|---|
| **신뢰도** | **17.62%** / **5.72%** | **26.74%** / **24.58%** |
| 코사인 | 17.12% / 4.59% | 20.94% / 18.61% |
| 향상도 | 14.12% / 0.75% | 6.20% / 3.44% |

결과 (실전 33,887명, 전체 / 새 시리즈)

| 방법 | 기록 전체 | 작품 1개 |
|---|---|---|
| 다음 편 2자리 + 장르 취향 (기존) | 13.56% / 1.54% | 5.33% / 2.58% |
| **다음 편 2자리 + 같이 본 작품 (신뢰도)** | 16.94% / 5.96% | **25.73%** / **23.58%** |
| 같이 본 작품만 (신뢰도) | 7.16% / 6.92% | 25.00% / 23.81% |
| (참고) EXP-10 최근 인기 섞기 | **23.57%** / 3.38% | 15.30% / 12.85% |
| (참고) EXP-10 전체 기간 인기도만 | 17.95% / 6.72% | 24.99% / 22.82% |

- **신규 유저 1등: 같이 본 작품 25.73%** (인기순 24.99%보다 높음). 고른 작품과 관련된 작품이라 개인 맞춤 의미도 있음
- 기록 있는 유저: 기존보다 +25% (13.56% → 16.94%), 새 시리즈 4배 (1.54% → 5.96%). 다만 최근 인기 섞기(23.57%)보다 낮음
- 향상도는 드문 작품 조합을 과대평가해서 가장 낮음 → 추천엔 신뢰도가 맞음

③ 결과 (실전 16,357명, 전체 / 새 시리즈)

| 방법 | 기록 전체 | 신규 유저 |
|---|---|---|
| 인기순 (전체 기간) | 4.22% / 4.25% | 14.35% / 13.33% |
| [MAL] 다음 편 2자리 + 장르 취향 (기존) | 10.08% / 1.42% | 5.06% / 2.37% |
| [MAL] 최근 인기 섞기 β=0.5 (EXP-12 최고) | 18.37% / 11.32% | 9.61% / 7.05% |
| [MAL] 같이 본 작품 | 9.79% / 1.36% | **16.82%** / **14.47%** |
| [AniList 태그] 다음 편 2자리 + 취향 (섞기 없음) | 14.62% / 2.06% | 7.00% / 4.36% |
| **[AniList 태그] 최근 인기 섞기 β=0.25** | **25.18%** / **13.77%** | |
| [AniList 태그] 전체 기간 인기만 | | 15.70% / 13.31% |

- **기록 있는 유저: AniList 태그 + 최근 인기 섞기(β=0.25)가 1등.** 기존 대비 2.5배 (10.08% → 25.18%), MAL 최고(18.37%)보다 +37%. 새 시리즈도 1등 (13.77%)
- 섞기 없이도 AniList 태그 취향이 MAL보다 높음 (14.62% vs 10.08%)
- **신규 유저: 같이 본 작품이 계속 1등** (16.82%)
- 같이 본 작품(기록 전체)이 9.79%로 EXP-12(14.30%)보다 크게 하락. 정답 기간 필터로 인기도·같이 본 횟수를 세는 유저가 38,887명 → 21,357명으로 줄어든 영향으로 보임 → 통계는 전체 유저 기록으로 세도록 수정 (→ EXP-14)

결정

- **취향 계산 기본값 = AniList 태그 전체** (코드 기본값 변경)
- 기록 있는 유저: 최근 인기 섞기 β=0.25 후보 (더 작은 값 확인 후 확정)
- 신규 유저: 같이 본 작품 유지
- 테마 태그만 표현은 채택 안 함 (비교용으로 코드 유지)

### 🔷 EXP-14 · 조합 모델

목표: 태그 취향 + 인기도 + 같이 본 작품을 섞은 조합 모델 완성. 기존·신규 유저 각각 최적 비중 찾기

바뀐 점

| 항목 | EXP-13 | EXP-14 |
|---|---|---|
| 인기도·같이 본 작품을 세는 기록 | 시험 유저 21,357명 기록만 | **전체 유저 47,181명** (821만 줄. 시험 유저는 정답 전 기록, 나머지는 2022-02 이전 기록) |
| 새 작품 8자리 점수 | 취향 + β × 인기도 | **취향 + β × 인기도 + γ × 같이 본 작품** (셋 다 0~1) |
| 기존 / 신규 유저 | 같은 설정 | **본 작품 5개 이하면 신규 유저 설정**으로 자동 전환 |

후보 범위 확인 (실전)

| 범위 | 정답이 안에 있는 비율 |
|---|---|
| 인기 상위 2,000편 (현재 후보) | 91.2% |
| 인기 상위 3,000편 | 95.7% |
| 인기 상위 5,000편 | 98.9% |
| 같이 본 횟수 표 3,000편 | 95.7% |

- 조합은 같이 본 횟수 표 3,000편도 후보에 넣음 → 실제 후보는 인기 상위 3,000편 (기존 유저는 + 최근 인기 300편). 후보 밖 정답 약 4%

고르는 기준 (미리 정함): 상황별 연습 5,000명 전체 점수 최고

A. 기존 유저: 최근 인기 β (연습, 전체 / 새 시리즈)

| β | 0.05 | 0.1 | 0.15 | **0.25** | 0.35 | 0.5 |
|---|---|---|---|---|---|---|
| 전체 | 17.02% | 19.94% | 22.44% | **24.92%** | 22.80% | 17.18% |
| 새 시리즈 | 3.41% | 6.30% | 9.64% | **13.65%** | 12.39% | 7.65% |

- 0.25에서 정점, 양옆으로 떨어짐 → EXP-13의 "범위 끝" 걱정 해소

B. 기존 유저: β=0.25 + 같이 본 작품 γ (연습)

| γ | 0 | 0.1 | **0.25** | 0.5 | 1 |
|---|---|---|---|---|---|
| 전체 | 24.92% | 27.34% | **28.12%** | 24.24% | 19.70% |
| 새 시리즈 | 13.65% | 15.67% | **15.94%** | 11.46% | 7.89% |

C. 신규 유저 (작품 1개 + 장르 3 + 테마 3): 전체 기간 인기 β × 같이 본 작품 γ (연습, 전체)

| β \ γ | 0.5 | 1 | 2 | 4 |
|---|---|---|---|---|
| 0 | 16.16% | 18.10% | 18.58% | 18.66% |
| 1 | 17.32% | 18.36% | **18.74%** | 18.72% |
| 4 | 18.32% | 18.50% | 18.72% | 18.62% |

- 참고: 같이 본 작품만 18.58%, 전체 기간 인기만 15.94%
- γ ≥ 2면 거의 같음 (18.6~18.7%) → 신규 유저는 같이 본 작품이 핵심, 인기도는 약간 보탬

선택: 기존 유저 → 최근 인기 β=0.25 + 같이 본 작품 γ=0.25 / 신규 유저 → 전체 기간 인기 β=1 + 같이 본 작품 γ=2

결과 (실전 16,357명, 전체 / 새 시리즈)

| 방법 | 기록 전체 | 신규 유저 |
|---|---|---|
| 인기순 (전체 기간) | 6.13% / 5.84% | 14.35% / 13.33% |
| 다음 편 2자리 + 취향 (섞기 없음) | 14.66% / 2.07% | |
| 다음 편 2자리 + 최근 인기 β=0.25 (EXP-13 최고) | 25.22% / 13.83% | |
| 다음 편 2자리 + 같이 본 작품 | 12.68% / 3.98% | 17.99% / 15.66% (EXP-13 최고) |
| 다음 편 2자리 + 전체 기간 인기만 | | 15.70% / 13.31% |
| **조합 (이번 선택)** | **27.55%** / **15.20%** | **18.55%** / **16.24%** |
| **조합 자동 설정** (5개 이하면 신규 설정) | **27.53%** / 15.17% | **18.55%** / 16.24% |

- 기존 유저: 25.22% → 27.55% (+9%), 새 시리즈 13.83% → 15.20%
- 신규 유저: 17.99% → 18.55% (+3%)
- 자동 설정이 두 상황 모두 최고와 같음 → **한 모델로 기존·신규 유저 모두 처리 가능**
- 전체 유저로 통계를 세니 같이 본 작품(기록 전체)이 9.79%(EXP-13) → 12.68%로 회복. 인기순도 4.22% → 6.13%

결정

- **v0.5 후보 = 조합 자동 설정** (`next_auto`): 다음 편 2자리 + 태그 취향 + 인기도 + 같이 본 작품, 기록 길이로 비중 자동 전환
- 코드 기본값 반영 (기존 유저 β=0.25 γ=0.25 최근 인기 / 신규 유저 β=1 γ=2 전체 기간 인기)
- 채점기 기본 실행도 이 모델 포함하도록 변경

### 🔷 EXP-15 · 모델 비교

목표: 이름 있는 추천 알고리즘과 같은 시험지로 비교. ML 도입 판단 근거 확보

비교 대상

| 알고리즘 | 방식 | 학습 | 계산 시간 (47,181명, 3,000편) |
|---|---|---|---|
| 인기순 | 많이 본 순서 | 없음 | — |
| 태그 취향 (콘텐츠 기반) | AniList 태그 코사인 유사도 | 없음 | — |
| 아이템 기반 CF (아마존 방식) | 같이 본 작품, 신뢰도 (EXP-11) | 없음 (세기만) | 5.5초 |
| **EASE** (Steck 2019) | 같이 본 횟수 표로 작품끼리 가중치를 한 번에 푸는 선형 모델 | **있음** (닫힌 해, 역행렬 1번) | 1.3초 |
| **ALS** (Hu·Koren·Volinsky 2008) | 유저·작품을 숫자 64개 벡터로 바꾸는 행렬 분해 | **있음** (10회 반복) | 83초 |

- SASRec(딥러닝)은 GPU 확보 후로 미룸
- 설정값 고르기 (연습 5,000명, 다음 편 2자리 + 해당 알고리즘, 전체 점수 최고)
  - EASE λ: 100 22.38% / **500 22.66%** / 2000 22.56% / 10000 21.48% → λ=500 (평평함)

EASE 학습 방법

| 항목 | 내용 |
|---|---|
| 학습 데이터 | MAL 표본 47,181명의 시청 기록 (821만 줄). 시험 유저는 정답 전 기록만, 나머지는 2022-02 전 기록만 → 정답 누출 없음 |
| 입력 | 인기 상위 3,000편의 같이 본 횟수 표 (G = XᵀX. X = 유저 × 작품, 봤으면 1) |
| 학습 | 작품마다 "나머지 작품들로 이 작품을 봤는지 맞히기"를 한 번에 풂. P = (G + λI)⁻¹, B = −P ÷ P의 대각 (열마다), B의 대각은 0. λ=500 |
| 결과물 | 3,000 × 3,000 가중치 표 B. 칸 = "작품 A를 봤으면 작품 B 점수에 더할 값" (마이너스 가능) |
| 추천 점수 | 유저가 본 작품들의 B 줄을 더함 |
| 시간 | 1.3초 (노트북 CPU, 반복 학습 없음) |

- 같이 본 작품(신뢰도)은 같은 표에서 비율을 세기만 함. EASE는 작품끼리 겹치는 정보를 빼고 작품마다 몫을 구함 → 1·2·3기처럼 비슷한 작품을 여러 개 본 유저도 같은 정보를 여러 번 세지 않음
- 지금은 채점할 때마다 새로 계산함. 서비스에서는 미리 계산한 표를 DB에 저장해서 씀 (4장)
  - ALS: **α=5 규제=1 18.24%** / α=20 규제=1 15.44% / α=20 규제=10 15.36% → α=5 규제=1

결과 1: 알고리즘끼리 맨몸 비교 (실전 16,357명, 규칙 없이 10개 전부 그 알고리즘, 전체 / 새 시리즈)

| 알고리즘 | 기록 전체 | 신규 유저 (작품 1개 + 칩) |
|---|---|---|
| 인기순 | 6.13% / 5.84% | 14.35% / 13.33% |
| 태그 취향 | 9.08% / 2.66% | 6.99% / 4.47% |
| 아이템 기반 CF (같이 본 작품) | 5.39% / 4.85% | **17.38%** / **15.86%** |
| **EASE** | **20.43%** / 6.21% | 14.48% / 12.10% |
| ALS | 12.18% / **6.49%** | 14.06% / 11.73% |

- **기록 있는 유저: EASE가 압도적 1등** (20.43%, 다른 알고리즘의 1.7~3.8배)
- 신규 유저: 아이템 기반 CF가 1등. 작품 1개만 있으면 "그 작품 본 사람이 본 작품"이 가장 정확
- 아이템 기반 CF는 단독으로는 약하지만(기록 전체 5.39%) 조합 안에서는 보탬이 됨 (EXP-14)

결과 2: 우리 조합의 "같이 본 작품" 자리 바꿔 끼우기 (실전, 자동 설정 비중 그대로, 전체 / 새 시리즈)

| 조합 안 행동 기반 부분 | 기록 전체 | 신규 유저 |
|---|---|---|
| 아이템 기반 CF (현재) | 27.55% / 15.20% | **18.55%** / **16.24%** |
| **EASE** | **31.29%** / 16.91% | 15.01% / 12.60% |
| ALS | 30.28% / **17.35%** | 14.15% / 11.72% |

- 기록 있는 유저: EASE로 바꾸면 27.55% → **31.29% (+3.7%p, +14%)**. 실전 16,357명 기준 표준오차 약 0.35%p라 우연이 아닌 차이
- 신규 유저: 현재(아이템 기반 CF) 유지가 맞음 (EASE·ALS로 바꾸면 하락)
- 바꿔 끼울 때 비중(γ=0.25)은 아이템 기반 CF 기준으로 고른 값 → EASE 기준으로 연습에서 다시 골라야 함 (→ EXP-16). 실전 결과만 보고 고르면 과적합 위험

결정

- **ML 도입 기준 충족:** 학습 모델(EASE)이 같은 시험에서 기존 방식을 확실히 이김 → 기록 있는 유저는 EASE 도입 후보
- 신규 유저는 아이템 기반 CF 유지 → 자동 설정에서 기록 길이로 행동 기반 부분도 바꾸는 구조
- 다음: EASE 조합의 비중 다시 고르기 (연습) → 실전 확인 → v0.5 확정 (EXP-16)

### 🔷 EXP-16 · EASE 조합 비중 + 전환 기준

목표: EXP-15에서 가장 좋았던 "조합 + EASE"의 비중을 연습 데이터로 다시 고르고, 본 작품 몇 개부터 EASE로 바꿀지 데이터로 정하기

방법

- 기존 유저 설정의 행동 기반 부분: 아이템 기반 CF → EASE (λ=500)
- ① 최근 인기 β=0.25로 두고 γ 고르기 → ② 그 γ로 β 고르기
- ③ 본 작품 N개만 남긴 연습 유저로 기존 유저 설정(EASE) vs 신규 유저 설정(아마존 방식) 비교. 신규 유저 설정이 이기는 가장 큰 N = 전환 기준
- 고르는 기준 (미리 정함): 연습 5,000명 전체 점수 최고 (같으면 새 시리즈)

① γ (연습 5,000명, 기록 전체, 최근 인기 β=0.25, 전체 / 새 시리즈)

| γ | 0.1 | 0.25 | **0.5** | 1 | 2 | 4 |
|---|---|---|---|---|---|---|
| 전체 | 28.74% | 31.90% | **32.16%** | 29.76% | 26.96% | 24.68% |
| 새 시리즈 | 16.00% | **17.10%** | 15.41% | 11.80% | 8.25% | 6.06% |

② β (γ=0.5)

| β | 0.15 | 0.25 | **0.35** |
|---|---|---|---|
| 전체 | 29.40% | 32.16% | **33.24%** |
| 새 시리즈 | 12.16% | 15.41% | **16.93%** |

- γ는 0.25~0.5에서 평평함. 1부터 새 시리즈가 크게 떨어짐
- **β=0.35가 시험 범위 끝** → 더 큰 값 확인 필요 (→ EXP-18)

③ 전환 기준 (연습 5,000명, 본 작품 N개만 남김, 시리즈 Hit@10)

| 남긴 작품 | 1개 | 2개 | 3개 | 5개 | 10개 | 20개 | 40개 |
|---|---|---|---|---|---|---|---|
| 기존 유저 설정 (EASE) | 12.52% | 15.54% | 16.78% | 19.78% | **23.24%** | **28.08%** | **30.50%** |
| 신규 유저 설정 (아마존 방식) | **18.46%** | **19.12%** | **19.74%** | **20.06%** | 21.04% | 21.26% | 19.06% |

- 5개까지 아마존 방식, 10개부터 EASE가 이김 → **전환 기준 5개** (EXP-14 임시값과 같음)
- 기록이 늘수록 EASE는 계속 오름 (12.52% → 30.50%), 아마존 방식은 20% 안팎에서 멈춤
- 5개에선 차이 작음 (20.06% vs 19.78%). 5~10개 사이는 안 잼 (→ EXP-18)

④ 실전 확인 (16,357명, 전체 / 새 시리즈)

| 상황 | 자동 설정 (EXP-14) | 자동 설정 (EASE, β=0.35 γ=0.5) |
|---|---|---|
| 기록 전체 | 27.53% / 15.17% | **33.07%** / **17.32%** |
| 신규 유저 (작품 1개 + 장르 3 + 테마 3) | 18.55% / 16.24% | 18.55% / 16.24% (같은 설정) |
| 작품 3개 | 19.42% / 13.88% | 19.42% / 13.88% (같은 설정) |
| 작품 10개 | 23.14% / 12.07% | **24.08%** / 11.05% |

- 기록 전체 27.53% → **33.07% (+5.5%p, +20%)**. 새 시리즈도 상승 (15.17% → 17.32%)
- EXP-15에서 비중을 안 바꾸고 EASE만 끼웠을 때(31.29%)보다 +1.8%p
- 작품 10개: 전체는 오르고 새 시리즈는 조금 내려감 (12.07% → 11.05%)

결정

- 기존 유저 설정 = EASE. 전환 기준 5개
- β가 범위 끝이라 확정 전에 범위 넓혀 다시 고름 (EXP-18)

### 🔷 EXP-17 · 3개 묶음 규칙 직접 비교

목표: "본 작품 2개를 같이 본 사람이 본 작품"(3개 묶음 규칙)을 쓰면 더 정확해지는지 직접 확인

방법

- 2개 묶음 규칙: A → C. 신뢰도 = A·C 둘 다 본 사람 ÷ A 본 사람 (지금 방식)
- 3개 묶음 규칙: {A, B} → C. 신뢰도 = A·B·C 셋 다 본 사람 ÷ A·B 둘 다 본 사람
- 규칙 점수 합치는 방법 2가지: **합산** (지금 방식) / **가장 센 규칙 하나** (Apriori 규칙 추천 방식)
- 3개 묶음 규칙은 A·B를 같이 본 사람이 10명 이상일 때만 (Apriori 최소 지지도). 계산량 때문에 2개 쌍 점수 상위 300편 안에서만 다시 매김
- 같이 본 작품만으로 추천 10개 (다음 편 자리·취향·인기도 없이 맨몸 비교)
- 작품 3개 / 10개만 남긴 실전 유저 16,357명. 기록 전체는 유저당 조건 쌍이 약 5,900개(본 작품 중앙값 109개)라 생략
- 설정값을 고르는 실험이 아니라 바로 실전 채점

결과 (실전 16,357명, 시리즈 Hit@10: 전체 / 보던 시리즈 / 새 시리즈)

| 방법 | 작품 3개 | 작품 10개 |
|---|---|---|
| 2개 규칙 합산 (지금) | 16.87% / 55.74% / 14.10% | 15.41% / 41.82% / 10.53% |
| 2개 규칙, 가장 센 규칙 하나 | 17.97% / 67.86% / 14.41% | **18.26%** / 60.57% / 10.43% |
| 2·3개 규칙, 가장 센 규칙 하나 | **18.17%** / 68.60% / 14.57% | 18.16% / 60.14% / 10.40% |
| 3개 묶음 규칙 합산 | 17.76% / 63.73% / 14.48% | 16.05% / 45.77% / 10.56% |

| 계산 (16,357명) | 작품 3개 | 작품 10개 |
|---|---|---|
| 2개 규칙 | 약 10초 | 약 14초 |
| 3개 묶음 규칙 | 약 10분 | 약 27분 |
| 유저당 조건 쌍 | 2.9개 | 43.1개 |

- 조건 쌍은 전부 같이 본 사람 10명 이상이라 최소 지지도 조건으로 빠진 쌍 없음
- **3개 묶음을 더해도 거의 안 오름**: 가장 센 규칙 방식 +0.2%p (작품 3개) / −0.1%p (작품 10개), 합산 방식 +0.9%p / +0.6%p
- 계산은 약 60~120배. 기록 전체(본 작품 중앙값 109개 → 조건 쌍 약 5,900개)는 이 방식으로 계산 불가
- 가장 센 규칙 하나가 합산보다 높음 (작품 3개 17.97% vs 16.87%, 10개 18.26% vs 15.41%)
  - 차이는 거의 보던 시리즈 정답 (67.86% vs 55.74%, 60.57% vs 41.82%). 새 시리즈는 비슷 (14.41% vs 14.10%, 10.43% vs 10.53%)
  - 속편은 "1기 본 사람 중 2기 본 비율"처럼 신뢰도가 높아서 가장 센 규칙이 되기 쉬운 것으로 보임
  - 조합 모델에선 보던 시리즈를 다음 편 2자리가 따로 맡음 → 조합 안에서 다시 비교 (EXP-18)

결정

- **3개 묶음 규칙은 쓰지 않음.** 오르는 폭(−0.1~+0.9%p)에 비해 계산 비용이 너무 큼
- 여러 작품이 겹치는 관계는 EASE가 데이터 전체에서 학습 (기록 많은 유저, EXP-15·16)
- 2개 규칙 점수 합치는 방법(합산 vs 가장 센 규칙 하나)은 조합 안에서 비교 → EXP-18

① 기존 유저 설정 β × γ (연습, 기록 전체, 전체 / 새 시리즈)

### 🔷 EXP-21 · 신작 흉내 + AniList 커뮤니티 추천

목표: 2022년 이후 작품처럼 같이 본 기록이 없는 작품을 v0.5가 얼마나 맞히는지, AniList 커뮤니티 추천("이거 좋아하면 이것도", 유저 투표)으로 얼마나 되찾는지

- RBP를 가장 많이 올리는 건 유형 취향 비중 낮추기. 하지만 0.35 이하면 싫은 글 노출이 최신순(0.74)보다 많아짐 → 개인화의 장점("싫은 글을 덜 봄")을 잃음
- RBP는 싫은 글을 "관심 없는 글"과 똑같이 셈. 실제로는 싫은 글이 더 나쁠 수 있어서 싫은 글 노출을 같이 봄
- 접속 100번 기준으로 보면 rank_scale 200도 확실한 개선이 아님: 좋은 글 열람 +5번 대신 다시 본 글 +30번 · 싫은 글 +6번
- **결정: 출발값 유지** (바꾸는 기준 미달. 좋은 점과 나쁜 점이 섞이고 가정에 기댄 결과). 유형 취향 비중·작품 취향 폭은 유저 테스트 기록(O/X 이유 "이런 유형 싫어요" 포함)으로 다시 정함
- 확실히 알게 된 것: 이미 보여준 횟수 감점은 꼭 필요 (없으면 RBP −35%, 다시 본 글 7.6장). 유형 취향 비중을 많이 낮추면 싫은 글이 최신순보다 많아짐

## 부록 B. 같이 본 작품 점수 계산

"같이 본 작품" = Apriori 신뢰도를 쓴 아이템 기반 협업 필터링

예시 (유저 4명 × 작품 3편, 봤으면 1)

| 유저 | 진격의 거인 | 귀멸의 칼날 | 주술회전 |
|---|---|---|---|
| A | 1 | 1 | 1 |
| B | 1 | 1 | 0 |
| C | 1 | 0 | 1 |
| D | 0 | 1 | 0 |

| 지표 | 계산 | 진격 → 귀멸 |
|---|---|---|
| 지지도 | 둘 다 본 사람 ÷ 전체 | 2 ÷ 4 = 50% |
| **신뢰도 (사용)** | 둘 다 본 사람 ÷ 진격 본 사람 | 2 ÷ 3 = **67%** |
| 향상도 | 신뢰도 ÷ 귀멸 본 사람 비율 | 0.67 ÷ 0.75 = 0.89 |

같이 본 사람 수는 행렬 곱셈 한 번으로 셈

- 위 표(유저 × 작품)를 전치해서 원래 표와 곱하면 **작품 × 작품 표**가 한 번에 나옴
- 칸 = 같이 본 사람 수, 대각선 = 그 작품을 본 사람 수 → 신뢰도 = 칸 ÷ 대각선

| | 진격 | 귀멸 | 주술 |
|---|---|---|---|
| 진격 | 3 | 2 | 2 |
| 귀멸 | 2 | 3 | 1 |
| 주술 | 2 | 1 | 2 |

추천 점수: 유저가 본 작품마다 "그 작품 → 후보" 신뢰도를 구해서 합침

- 합산: 전부 더함. 여러 작품과 관련된 후보일수록 점수가 커짐 (EXP-11~16)
- 가장 센 규칙 하나: 그중 가장 큰 값만 씀 (Apriori 규칙 추천 방식). v0.5 신규 유저 설정 (EXP-18)
- 예) 진격·체인소 맨을 본 유저, 후보 도쿄 구울 (진격 → 0.4, 체인소 → 0.5): 합산 0.9 / 가장 센 규칙 하나 0.5

원조 Apriori와 차이

| | 원조 Apriori (1994) | 우리 |
|---|---|---|
| 찾는 것 | 자주 같이 나오는 묶음 (1개 → 2개 → 3개 …) | 2개 묶음 규칙 (A → B)만 |
| 세는 방법 | 묶음 크기마다 데이터를 다시 훑어서 셈. 드문 묶음은 다음 단계에서 미리 뺌 (Apriori 원리) | 행렬 곱셈 한 번으로 모든 쌍을 셈 |
| 작품 3,000편 기준 묶음 수 | 2개 약 450만, 3개 약 45억, 4개 약 3.4조 | 2개 약 450만 쌍만 |
| 계산 시간 | 해 보지 않음 | **5.5초** (유저 47,181명 · 기록 821만 줄 · 작품 3,000편, 노트북 CPU) |
| 규칙 여러 개 합치기 | 기록에 맞는 규칙 중 가장 센 규칙 하나 | 합산(아이템 기반 CF, Deshpande & Karypis 2004)으로 시작 → 조합 안에서 비교해 신규 유저 설정은 가장 센 규칙 하나로 (EXP-18) |

- 추천 분야에서는 **아이템 기반 협업 필터링**이라고 부름. 아마존이 2003년에 공개한 방식과 같은 원리
- 정확히는 "Apriori의 신뢰도를 작품 사이 유사도로 쓴 아이템 기반 CF"

3개 이상 묶음

묶음이 커질수록 같이 본 사람이 빠르게 줄어듦 (유저 300명이 본 작품에서 묶음 6,000번 무작위 추출, 47,181명 기준)

| 묶음 크기 | 다 본 사람 중앙값 | 하위 10% |
|---|---|---|
| 1개 | 7,346명 | 1,167명 |
| 2개 | 1,684명 | 180명 |
| 3개 | 522명 | 43명 |

- 작품 하나 더할 때마다 약 1/3 ~ 1/4로 줄어듦. 3개 묶음 중 같이 본 사람 30명 미만 6.8% (2개 묶음 0.6%)
- 규칙 신뢰도는 조건 쪽 묶음을 본 사람 수로 나눈 값 → 조건이 커질수록 우연에 흔들림

| 규칙 | 예 | 신뢰도 10% 규칙의 95% 오차 (중앙값 / 하위 10%) |
|---|---|---|
| 2개 묶음 규칙 | A → C | ±0.7%p / ±1.7%p |
| 3개 묶음 규칙 | {A, B} → C | ±1.4%p / ±4.4%p |
| 4개 묶음 규칙 | {A, B, D} → C | ±2.6%p / ±9.0%p |

- 서비스 초기(유저 테스트 20명 수준)에는 3개 이상 묶음 규칙을 세울 수 없음

직접 비교 (EXP-17, 같이 본 작품만으로 추천, 실전 시리즈 Hit@10)

| 방법 | 작품 3개 | 작품 10개 | 계산 (작품 3개 / 10개) |
|---|---|---|---|
| 2개 규칙, 가장 센 규칙 하나 | 17.97% | 18.26% | 약 10초 / 14초 |
| + 3개 묶음 규칙 | 18.17% | 18.16% | 약 10분 / 27분 |
| 2개 규칙 합산 | 16.87% | 15.41% | 약 10초 / 14초 |
| + 3개 묶음 규칙 | 17.76% | 16.05% | 약 10분 / 27분 |

- 3개 묶음 규칙은 오르는 폭이 작고(−0.1~+0.9%p) 계산은 60~120배 → 안 씀
- 여러 작품이 겹치는 관계는 기록 많은 유저에서 EASE가 데이터 전체로 한 번에 학습 (선형 모델)
- 두 작품이 함께 있어야만 생기는 효과(비선형)는 EASE도 못 잡음 → 데이터가 쌓이면 딥러닝(SASRec 등)으로 확인

합산 vs 가장 센 규칙 하나

| 비교 | 합산 | 가장 센 규칙 하나 |
|---|---|---|
| 맨몸 (EXP-17, 실전, 작품 3개 / 10개) | 16.87% / 15.41% | **17.97%** / **18.26%** |
| 조합 안 신규 유저 설정 (EXP-18, 연습, 작품 2·3·5개 평균) | 19.64% | **19.95%** |

- 맨몸 차이는 대부분 보던 시리즈(속편) 정답. 조합 안에선 다음 편 2자리가 속편을 맡아서 차이가 작아짐
- 작품 1개(온보딩 직후)면 둘이 같음

## 부록 C. 기록 길이 자동 전환까지

| 순서 | 실험 | 발견 | 다음 행동 |
|---|---|---|---|
| 1 | EXP-08 짧은 기록 시험 | 작품 1~5개만 있으면 인기순이 개인 맞춤을 이김 (작품 1개: 인기순 16.54% vs 장르 취향 7.88%) | 신규 유저에겐 다른 재료 필요 |
| 2 | EXP-11 같이 본 작품 | 작품 1개만 있어도 "그 작품 본 사람이 본 작품"이 전체 기간 인기보다 정확 (25.73% vs 24.99%) | 신규 유저 재료 = 같이 본 작품 |
| 3 | EXP-13 AniList 태그 | 기존 유저는 태그 취향 + 최근 인기, 신규 유저는 같이 본 작품이 1등 → 상황별 1등이 다름 | 상황별로 다른 설정을 쓰는 구조 필요 |
| 4 | EXP-14 조합 모델 | 본 작품 5개 이하면 신규 설정으로 자동 전환 → 두 상황 모두 1등과 같은 점수 (27.53%, 18.55%) | 전환 기준 5개는 임시값 |
| 5 | EXP-15 모델 비교 | 기존 유저: EASE가 압도적 (단독 20.43%, 조합 31.29%). 신규 유저: 아마존 방식이 1등 (단독 17.38%), EASE로 바꾸면 하락 (18.55% → 15.01%) | 행동 기반 부분도 기록 길이로 전환 |
| 6 | EXP-16 전환 기준 | 작품 1·2·3·5개는 아마존 방식, 10·20·40개는 EASE가 이김. 기록이 늘수록 EASE만 계속 오름 (12.52% → 30.50%), 아마존 방식은 20% 안팎에서 멈춤 | 전환 기준 5개 |
| 7 | EXP-18 v0.5 확정 | 신규 유저 설정을 가장 센 규칙 하나로 바꾸니 7개까지 신규 설정이 이김 (7개는 거의 동점) | 전환 기준 7개로 v0.5 확정 |

- 아마존 방식(신뢰도)은 "A를 본 사람 중 B를 본 비율"을 그대로 씀 → 작품 1개만 있어도 바로 의미 있는 점수
- EASE는 여러 작품이 같이 있을 때를 기준으로, 겹치는 정보를 나눠서 작품마다 몫을 정하도록 학습됨 → 작품이 몇 개뿐이면 각 작품의 몫만으로는 점수가 약함. 기록이 많을수록 강해짐
