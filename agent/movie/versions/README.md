|---|---|---|
| `movie_info_agent_V2.3.py` | 2026-09-20 | 콜랩 노트북(Movie_Info_agent_V2.3)을 스크립트로 옮긴 판. 에이전트 여섯(재료 판정 · 재료 정리 · 글쓰기 · 편집국장 · 판정관 · 고치기), 시리즈 용어집 |
| `movie_review_agent_V1.8.py` | 2026-09-20 | 콜랩 노트북(Review_agent_V1.8)을 스크립트로 옮긴 판. 글쓰기 · 형태 검사 · 판정관 · 업로드 규칙 |
| `movie_info_agent_V2.4.py` · `movie_review_agent_V1.9.py` | 2026-09-22 | 편집국장 · 판정관이 앞 판 판정과 앞 판 글을 받는다(REMEMBER_PREVIOUS). 판 종류(첫 판 · 고침 · 새로 씀), 고쳐짐 / 남음 / 새로 생김 / 못 봄 대조, 점수는 앞 점수에서 출발. 탈락보관이면 합계 최고 판 글을 남긴다(KEEP_BEST_ROUND). 노트북에서 `__file__` 없으면 지금 폴더 |
| (현재 V2.5 · V2.0) | 2026-09-22 | 글이 흥미롭지 않다 · 틀에 박혔다(PM) → 음악 v3.5 방식. 온도 · 시작점 · 배치(리뷰는 접근도) 뜻글을 작가 · 편집국장 · 판정관이 같이 받음(`order_text`). 정보: 재료 정리가 독자의 질문 · 답 · 문단 계획을 내고 첫 문단 질문 → 마지막 문단 답, 편집국장 [주문대로 갔는가] · [독자의 질문] · [되풀이], `(목소리: 미상)` 괄호도 잡음. 리뷰: [하나를 잡는다](장면 · 선택 · 인물 하나를 끝까지), 판단 이름표 문장 금지(코드도 잡음). 둘 다 같은 꼴 문장 금지 · 비유 허용 · `shape_form_check`(문장 길이 단조 · 제목/'이 영화'로 문단 열기 · 정보는 출연진 몰림 · 리뷰는 문단 길이 단조) |
