v2.6~v2.8은 커밋 전에 덮어써서 따로 없다. 바뀐 내용은 `music_review_agent.py` 머리 주석에 판마다 적혀 있다.
v3.0~v3.2는 콜랩에서만 만들어 `.py`가 없다. 노트북은 루트에 있다. 바뀐 내용은 머리 주석에 있다.
현재 판(`music_review_agent.py`)은 v3.3에 콜랩 zip 자동 내려받기(`콜랩_끝나면zip`, 9/22)를 더한 것이다.
v3.3 + zip + 앞판기억(편집국장이 앞 판 점수 · 문제 목록을 받는다)은 커밋 ad0c139다. 사본은 따로 없다.

노트북(`.ipynb`)은 루트에 판마다 남긴다. git에는 안 올린다.
