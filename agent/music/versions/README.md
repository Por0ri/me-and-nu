# versions — 지난 판 보관

`music_review_agent.py`(상위 폴더)가 현재 판이다. 판을 올릴 때 지난 판을 여기에 그대로 복사해 둔다. 지우지 않는다.

| 파일 | 날짜 | 바뀐 것 |
|---|---|---|
| `music_review_agent_v2.5.py` | 2026-09-20 | 콜랩 노트북을 스크립트로 옮긴 첫 판. 검색 엔진 + 차단 목록, RSS, 위키 평가 절 |
| `music_review_agent_v2.9.py` | 2026-09-21 | 이즘·아이돌로지 API, run_one, 곡 순서 배치, 곡메모·아티스트 말, 재료 보강, MusicBrainz 별칭 |
| `music_review_agent_v3.3.py` | 2026-09-21 | 올림 관문을 치명·고칠것·사소로 나눔, Jev(langchain-typesafe) 재료 거르기·문제 무게, 실패해도 한 번 더, 후보 다시 채우기, 교정자는 걸렸을 때만, 동시앨범. 콜랩 노트북(v3.3)에서 .py로 되돌린 것 |
| (현재 v3.4) | 2026-09-22 | 편집국장이 앞 판 글 본문도 받는다. [앞 판 글]과 [이번 글 — N차 · 판 종류]를 나란히 준다. 앞판대조에 '앞 판에서 못 봄' 추가. 기록에 판 종류. 탈락이면 점수 최고 판 글 저장(최고판저장). v3.3 + zip + 앞판기억(커밋 ad0c139) 다음 판이다 |

v2.6~v2.8은 커밋 전에 덮어써서 따로 없다. 바뀐 내용은 `music_review_agent.py` 머리 주석에 판마다 적혀 있다.
v3.0~v3.2는 콜랩에서만 만들어 `.py`가 없다. 노트북은 루트에 있다. 바뀐 내용은 머리 주석에 있다.
현재 판(`music_review_agent.py`)은 v3.3에 콜랩 zip 자동 내려받기(`콜랩_끝나면zip`, 9/22)를 더한 것이다.
v3.3 + zip + 앞판기억(편집국장이 앞 판 점수 · 문제 목록을 받는다)은 커밋 ad0c139다. 사본은 따로 없다.

노트북(`.ipynb`)은 루트에 판마다 남긴다. git에는 안 올린다.
