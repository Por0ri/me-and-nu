# versions — 지난 판 보관

`music_review_agent.py`(상위 폴더)가 현재 판이다. 판을 올릴 때 지난 판을 여기에 그대로 복사해 둔다. 지우지 않는다.

| 파일 | 날짜 | 바뀐 것 |
|---|---|---|
| `music_review_agent_v2.5.py` | 2026-09-20 | 콜랩 노트북을 스크립트로 옮긴 첫 판. 검색 엔진 + 차단 목록, RSS, 위키 평가 절 |
| `music_review_agent_v2.9.py` | 2026-09-21 | 이즘·아이돌로지 API, run_one, 곡 순서 배치, 곡메모·아티스트 말, 재료 보강, MusicBrainz 별칭 |

v2.6~v2.8은 커밋 전에 덮어써서 따로 없다. 바뀐 내용은 `music_review_agent.py` 머리 주석에 판마다 적혀 있다.

노트북(`.ipynb`)은 루트에 판마다 남긴다. git에는 안 올린다.
